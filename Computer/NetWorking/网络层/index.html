    网络层¶

    网络层负责在不同网络之间转发分组。它使用 IP 地址标识主机或接口，使用路由和转发机制决定分组下一步应该交给哪个接口。

    IP 分组¶

    IPv4 分组由首部和数据两部分组成。首部中最重要的字段包括源地址、目的地址、生存时间 TTL、上层协议号和分片相关字段。

    • TTL 每经过一个路由器通常减 1，减到 0 时分组被丢弃，避免分组在环路中无限循环。
    • 协议号用于标识上层协议，例如 TCP、UDP 和 ICMP。
    • 分片允许一个较大的 IP 分组适应链路的最大传输单元，但会增加重组和丢包代价。

    IPv4 地址与子网¶

    IPv4 地址由 32 位组成，通常写成四段十进制数。CIDR 用“地址/前缀长度”表示网络部分，例如 192.168.1.0/24 表示前 24 位是网络号。

    对于一个普通的 /24 子网：

    项目 地址范围
    网络地址 192.168.1.0
    可分配主机地址 192.168.1.1 到 192.168.1.254
    广播地址 192.168.1.255

    主机判断两个地址是否在同一子网时，会分别将地址与子网掩码按位与，比较得到的网络地址是否相同。

    路由与转发¶

    路由是计算到达目的网络的路径，转发是路由器根据路由表实际发送当前分组。路由表通常包含目的网络、子网掩码、下一跳和出接口。

    路由器查表时采用最长前缀匹配：如果多条路由都能匹配目的地址，选择前缀长度最长的那一条，因为它表示更具体的网络。

    Text Only
    收到分组
  -> 检查目的地址和首部
  -> 查找最长匹配路由
  -> TTL 减 1
  -> 重新计算校验信息
  -> 从对应接口发送

    常见协议¶

    ARP¶

    ARP 在同一局域网内把 IPv4 地址解析为 MAC 地址。主机先广播 ARP 请求，目标主机单播返回 ARP 响应，结果通常会暂存在 ARP 缓存中。

    DHCP¶

    DHCP 用于自动分配 IP 地址、子网掩码、默认网关和 DNS 服务器。经典流程可以记为 DORA：Discover、Offer、Request、ACK。

    ICMP¶

    ICMP 用于报告网络层错误和诊断信息。ping 使用回显请求和回显应答，traceroute 则利用 TTL 逐跳变化观察路径。

    路由算法¶

    • 距离向量：路由器周期性交换到各目的网络的距离，典型协议是 RIP。
    • 链路状态：路由器发布链路状态信息，每个路由器建立完整拓扑后独立计算最短路径，典型协议是 OSPF。
    • 域间路由：自治系统之间使用 BGP，根据路径属性选择跨域路径。

    NAT¶

    NAT 将私有地址转换为公网地址，使多个内网主机共享有限的公网地址。端口地址转换还会同时记录端口映射，因此外部主机通常无法直接主动访问内网主机。

    网络层和链路层的区别

    IP 地址描述跨网络的逻辑位置，MAC 地址描述当前链路上的接口。路由器根据 IP 决定跨网路径，交换机根据 MAC 决定局域网内的转发端口。
