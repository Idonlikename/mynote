    Matplotlib Pyplot¶

    Pyplot 是 Matplotlib 的子库，提供了和 MATLAB 类似的绘图 API。

    Pyplot 是常用的绘图模块，能很方便让用户绘制 2D 图表。

    Pyplot 包含一系列绘图函数的相关函数，每个函数会对当前的图像进行一些修改，例如：给图像加上标记，生新的图像，在图像中产生新的绘图区域等等。

    使用的时候，我们可以使用 import 导入 pyplot 库，并设置一个别名 plt：

    import matplotlib.pyplot as plt

    这样我们就可以使用 plt 来引用 Pyplot 包的方法。

    以下是一些常用的 pyplot 函数：

    • plot()：用于绘制线图和散点图
    • scatter()：用于绘制散点图
    • bar()：用于绘制垂直条形图和水平条形图
    • hist()：用于绘制直方图
    • pie()：用于绘制饼图
    • imshow()：用于绘制图像
    • subplots()：用于创建子图

    除了这些基本的函数，pyplot 还提供了很多其他的函数，例如用于设置图表属性的函数、用于添加文本和注释的函数、用于保存图表到文件的函数等等。

    所有的图像都需要在plt.show()的时候才会输出，可以看作有一个画板，后一个相同的操作会覆盖前一个相同操作，所以一个plt.show()只会输出指令前最终的图表，并且会清空原来画板中的全部内容（不会输出任何内容）。也就意味着不能继续用前一个图表的标签，注释等。

    折线图¶

    单数值折线图¶

    Python
    import matplotlib.pyplot as plt

numlist=([1,2,3,4])    #括号中括号([])，组成作图的点的值

xpoints = numlist    #若不定义X轴只定义y轴，默认是0 1 2 3
ypoints = numlist    #由此可见直接用列表是可以的。明面上不行（不规范），但是本身可行。

#也可以：xpoints=([100,458])#各个点的坐标
#       ypoints=([300,100])


plt.plot(ypoints,marker='x'，label='y-label')#用一个值序列做一个折线的折线图，并且用marker的赋值来描点(一般是'o'和'x'代表点和叉)。此处不定义x，若不定义x程序自己则会用默认数值。

plt.show()#输出作图

    以折线图为例补全图标¶

    图标属性¶

    包含图表标题：plt.title('')

    x轴标签：plt.xlabel('')

    y轴标签：plt.ylabel('')

    折线标签：plt.plot(... , label='') 和 plt.legend()

    Python
    import matplotlib.pyplot as plt
numlist=([1,2,3,4])  
xpoints = numlist    
ypoints = numlist    

#标签操作
plt.title("title")  #提供一个图表的标题

plt.xlabel("x-label")  #提供x轴的数据的标签,x轴数据的含义
plt.ylabel('y-label')  #提供y轴地数据的标签,y轴数据的含义

plt.plot(ypoints,marker='x',label='y-label')
#用一个值序列做一个折线的折线图，并且用marker的赋值来描点(一般是'o'和'x'代表点和叉)。
#再定义一个label用于标注折线的含义（也就是再一次标注y轴）。
plt.legend()#直接用plot是没有用的，需要legend()函数才会有效显示

plt.show()

    给x,y轴都标注上相应的标签，并且图表有相应的标题。同时折线本身也有了注释（主要用于多折线情况用于讲解区分）。

    参考线¶

    plt.axhline(y=0)括号内填入x,y的赋值式

    在制作图表的时候，难免会遇到需要对比的情况（如对比折线图整体是否在0之上或0之上）

    这时候参考线会起到相应的作用，为我们在观测数据的时候有更好的对照物。

    这里以零线为例：

    Python
    import matplotlib.pyplot as plt
numlist=([1,2,3,4])    

xpoints = numlist    
ypoints = numlist    

plt.plot(ypoints,marker='o')

plt.axhline(y=0)#零线
plt.show()

    plt.axhline()在此处以零线为例，实际情况可以灵活使用。

    import matplotlib.pyplot as plt
import numpy as np

x = np.arange(0, 4 * np.pi, 0.1)

    散点图¶

    plt.scatter(x,y,s,alpha,c,camp)

    绘制x y的散点图，s控制点的大小；alpha控制点的不透明度；c控制颜色，以上都可以通过列表来改变一个图内各个点的状态属性；c也可以通过等于一个和y相关的z来控制所有散点的颜色类似于camp；camp等于特定的值来控制热力图的颜色，但需要在前面加一个c=y,来让y变换颜色

    Python
    import matplotlib.pyplot as plt

x = ([1, 2, 3, 4, 5, 6, 7, 8, 8])

y = ([1, 4, 9, 16, 7, 8, 25, 10, 1])

plt.scatter(x, y,s=100)  

plt.colorbar()  # 输出右侧一个颜色的对照图
plt.show()

    柱状图¶

    matplotlib.pyplot.bar(x, height, width: float = 0.8, bottom = None, *, align: str = ‘center’, data = None, **kwargs)

    • 其参数具体如下含义：
    • x 表示 x 坐标，数据类型为 float 类型，一般是通过 np.arange() 生成的固定步长列表。
    • height 表示柱状图的高度，也就是 y 坐标值，数据类型为 float 类型，一般为一个列表，包含生成柱状图的所有 y 值。
    • width 表示柱状图的宽度，取值在 0~1 之间，默认值为 0.8。
    • bottom 表示柱状图的起始位置，也就是 y 轴的起始坐标，默认值为 None。
    • align 表示柱状图的中心位置，“center”，“lege” 边缘，默认值为 ’center’。
    • color 表示柱状图颜色，默认为蓝色。
    • alpha 表示透明度，取值在 0~1 之间，默认值为 1。
    • label 表示标签，设置后需要调用 plt.legend() 生成。
    • edgecolor 表示边框颜色 (ec)。
    • linewidth 表示边框宽度，浮点数或类数组，默认为 None (lw)。
    • tick_label 表示柱子的刻度标签，字符串或字符串列表，默认值为 None。
    • linestyle 表示线条样式 (ls)。
    Python
    import matplotlib.pyplot as plt

x=(['a','b','c','d'])#需要的是各个柱形的标签
y=([3,5,6,1])#柱形的值

plt.bar(x,y)#纵向柱形图，其他参数：width是每一个住的宽度（取值0~1，默认是0.8）
plt.show()

    Python
    import matplotlib.pyplot as plt

x=(['a','b','c','d'])#需要的是各个柱形的标签
y=([3,5,6,1])#柱形的值

plt.barh(x,y)#横向柱形图，不用width更改宽度，用height
plt.show()

    柱状图：

    Python
    import matplotlib.pyplot as plt
import numpy as np

a = ([20, 35, 30, 35, 27])
b = ([25, 32, 34, 20, 27])

# 设置相关参数

index = np.arange(len(a))

bar_width = 0.35


# 画柱状图

# 第一个参数代表的是每一个柱子的位置情况

# 第二个参数代表该柱子的高度

# width:代表每一个柱的宽度，label:对应的是哪一个

plt.bar(index, a, width=bar_width, label="a")

plt.bar(index + bar_width, b, width=bar_width, label="b")


# 设置柱状图标示（数字）

# zip: x和y作为循环变量，循环条件对应的谁，按顺序来走，x -> index, y -> a

# x代表横坐标的位置，y代表数字的大小

# 第一个参数：数字的横坐标位置，需要与柱状图保持一致

# 第二个参数：数字的纵坐标位置，需要略高于柱子一点点

# 第三个参数：数字的大小

# ha属性代表数字在此柱状图的哪个横向位置，如若不定义，则默认靠右

# va属性代表数字在此柱状图的哪个纵向位置，如若不定义，则默认与柱状图贴着,top是向下，bottom是向上

for x, y in zip(index, a):
    plt.text(x, y + 0.3, y, ha="center", va="bottom")

for x, y in zip(index, b):
    plt.text(x + bar_width, y + 0.3, y, ha="center", va="bottom")


 # 设置刻度范围/坐标轴名称等

# y轴显示的取值范围

plt.ylim(0, 40)  # 取值范围

plt.xlabel("a")

plt.ylabel("b")

# 横坐标的值的定义，如若不定义，默认为0 1 2 3 4

# 第一个参数为横坐标的位置，柱状图是一列的情况下，与数据的宽度相同即可，若是两列需要在数据宽度的后面加上 + 柱子的宽度 / 2

# 第二个参数为横坐标的值


plt.xticks(index), ("A", "B", "C", "D", "E")

plt.xticks(index + (bar_width / 2), ("A", "B", "C", "D", "E"))

plt.show()
