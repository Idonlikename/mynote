    Numpy基础¶

    NumPy是一个用于数值计算的开源Python库，它提供了一个强大的多维数组对象和用于处理这些数组的工具。

    NumPy 中的数组对象称为（类型）-ndarray

    Python中的矩阵的格式为[[第一行内容],[第二行内容],[第三行内容]]

    需要外部一个[]来表明矩阵的范围，内部的[]表明某行内容，第几个[]表明第几行。单一的用[]array创建的是数组

    对于所有创建矩阵的函数，内部元素类型默认是float，可以在参数后面输入（dtype = int）来改变类型

    数组和列表的数据差别是数组的[]内，无逗号。

    Axis=1是对列进行操作。有的操作默认是axis=0，有的则是在不声明的情况下不会对行列进行处理

    创建数组¶

    这里并不会提及mat与matrix，因为在NumPy的较新版本中，matrix 函数已经被弃用。NumPy团队鼓励用户使用标准的多维数组（numpy.ndarray）来处理矩阵运算，因为它们更加通用和灵活。如果你需要进行矩阵乘法，可以使用 @ 运算符或者 numpy.dot 函数，或者使用 numpy.linalg 模块中的函数来执行矩阵相关的操作。mat 函数用于创建矩阵对象，但它实际上是返回一个2维的NumPy数组（numpy.ndarray），而不是矩阵类型。这意味着，虽然它看起来像是一个矩阵，但在进行算术运算时，它不会自动应用矩阵乘法规则，除非你明确指定。

    修改数组值（Modify Array Values）：¶

    默认情况下，nditer将输入数组视为只读对象。要修改数组元素，必须指定读写（read-write）或只写（write-only）模式。这是由每个操作数标志控制的。一般而言，Python中的赋值只需更改本地或全局变量字典中的引用，而不是修改现有变量。

    将元素扩大两倍

    Python

#...代表全部数据，x[...]代表全部x

x[...]=2*x

    百分比操作¶

    np.percentile代码的百分比操作

    python默认排序由小到大，所以在百分比操作的时候，python自身已经对这组数组进行了升序排序，寻找这组数里排在50%位置的数值，每个数字的百分位置是根据100/(num-1)分配的。此处称分位距离。

    此处为例：100/5=20，可知每个数值位于20*n的位置上。（起始位置仍为0）。后根据百分位置前后数值来进行计算。

    计算：距离最近的两个数值位，由计算点位到上下点位的百分距离，占分位距离的百分比（相加等于1），乘以上下数并相加

    Python
    np.percentile(a, 50)#这组数组的50%位置的数据的数值

#axis为0 在列上求 每一列的50%的分位数

np.percentile(a,50,axis=0)

#在行上求 每一行的50%的分位数

np.percentile(a,50,axis=1)

print(np.percentile(a,50,axis=1,keepdims=True)) #求每一行的50%的分位数 且保持维度不变（不变成数组，仍保持其矩阵，但列数变为1）

np.median(a,axis=1)#每一行的中位数

    数据查找¶

    np.where()一种返回索引的查找，查找数组中满足条件的元素的索引。

    明显的，他的代码句式是—被查找的数组名称+满足何条件。注意：条件只能使用一个，因为它返回的是准确的索引而非布尔值

    Python
    x=np.arange(9).reshape(3,3)

print('大于3的数据：')

y = np.where(x>3) #返回x中大于3的元素的索引

print(x[y])

    定义条件查找¶

    Python
    x=np.arange(9).reshape(3,3)

print('1')

print(x)

condition = np.mod(x,2) == 0#定义条件，定义：如何判断（判断的条件），需要的结果，还需要判断的数组就在函数内。此处为选择偶数元素

print(condition)#返回一个跟判断的矩阵形状相同的矩阵，数据元素为各个元素的判断结果。

print(np.extract(condition,x))#对矩阵中所有的数据以此判断，判断是否符合条件。当condition=True时提取。实际上就是返回对应时True的元素，组成一个新一维数组。

    #定义一个条件continue需要三部分组成，continue = 判断数组x元素的条件和数组x本身—以及判断的依据（True or False）。Continue本身会获得一个跟数组同模的由布尔值组成的新数组。通过extract函数来返回各个位置对应是True的元素来组成一个新的一维数组返回。
