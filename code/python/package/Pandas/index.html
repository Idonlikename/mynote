    合并操作¶

    Python
    1
    pd.merge(df1, df2, on='value', how='inner')  # 假设我们使用inner join  不保留缺失值

    如果你希望合并后的保留缺失值，可以使用outer：

    Python
    1
    merged_df = pd.merge(df1, df2, on='value', how='outer')

    如果你只想保留df1中的行，并且只合并df2中与df1有相同value的行，可以使用left：

    Python
    1
    merged_df = pd.merge(df1, df2, on='value', how='left')

    反之，如果你想保留df2中的行，可以使用right：

    Python
    1
    merged_df = pd.merge(df2, df1, on='value', how='right')  # 注意这里df1和df2的顺序

    复杂¶

    1. 使用不同的列进行合并： 使用left_on和right_on参数分别指定左侧和右侧DataFrame中用于合并的列。
    Python
    1
    merged_df = pd.merge(df1, df2, left_on='key1', right_on='key2', how='inner')
    1. 合并时保留合并信息： 使用indicator参数，这将添加一个新列到合并后的DataFrame中，指示每行的来源（例如，both表示两个DataFrame中都有匹配，left_only表示只有左侧DataFrame中有匹配）。
    Python
    1
    merged_df = pd.merge(df1, df2, on='value', how='inner', indicator=True)
    1. 使用复杂的条件进行合并： 如果你需要根据多个条件或更复杂的逻辑进行合并，你可以使用merge函数的suffixes参数来处理列名冲突，然后使用条件语句来过滤或选择特定的行。
    Python
    1
2
3
    merged_df = pd.merge(df1, df2, on='value', how='inner', suffixes=('_df1', '_df2'))
# 然后根据需要使用条件过滤
filtered_df = merged_df[(merged_df['condition_column_df1'] > some_value)]
