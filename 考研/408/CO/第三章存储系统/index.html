    存储系统¶

    存储器概述¶

    存储器的分类，可以按照四种方式进行区分

    存储器的区分¶

    按作用区分¶

    高速缓冲存储器：即Cache，缓存。介于CPU与主存之间，主要用于解决：主存和CPU之间的读写速度不匹配的问题，一般有多层缓存。

    主存储器：即内存。主存主要用于交换数据（和辅存之间相互交换，可以实现虚拟内存，解决内存不足的问题），以及存放计算机运行期间所需要的程序和数据。

    辅助存储器：即外存。是计算机存储信息的场所。

    以上，从上至下，读写速度减慢，存储空间增大，成本降低。

    上层作为下一层的高速缓存。分层结构的目的主要是解决，存储、读写速度、成本三者之间的矛盾。

    • 主存和Cache之间的数据调动由硬件完成，对所有的程序员透明
    • 主存和辅存之间的数据调动由硬件和操作系统完成，对应用程序员透明

    按存储介质区分¶

    磁表面存储器：磁盘，磁带

    磁芯存储器

    半导体存储器：MOS型存储器，双极型存储器

    光存储器：光盘

    按存取方式区分¶

    随机存取存储器 -RAM¶

    读写任何一个存储单元所需要的时间相同。读写速度快，灵活。

    串行存储器-SAM&&DAM¶

    存取速度受存储单元地址影响的存储器。

    分为以下两种串行存储器：

    • 顺序存取存储器SAM：读写速度受存储单元的地址影响。如磁带

    • 直接存取存储器DAM：介于顺序存取和随机存取之间，一般先找到整个存储器的某个小区域，再在小区域进行顺序查找。如磁盘的磁头，先找到磁道，再转动磁盘查找。

    相联存储器-CAM¶

    按照内容检索到地址的存储器。和以上的区别主要是其按照内容进行访问

    信息的可更改性¶

    ROM¶

    只读存储器ROM（READ ONLY MEMORY）：只能读不能写的存储器。BIOS也存储在ROM中

    RAM¶

    读写存储器，也称随机存取存储器。（Random Access Memory）即可读，可写的存储器。

    按信息可保存性区分¶

    • 非易失性存储器：断电后可保存存储信息的，外存。

    • 易失性存储器：断电后不可保存存储信息的，内存缓存，都属于易失性存储器。

    对于信息读出，是否破坏信息，分为：

    • 破坏性读出：信息读出后，原存储的信息被破坏，DRAM

    • 非破坏性读出：信息读出后，原存储的信息不会被破坏，光盘，磁盘

    存储器的性能指标¶

    存储容量、单位成本、存储速度。三者只能取其二，不可三者兼得。

    存储容量，参考第一章当中的内容：

    MAR位数反映存储单元的个数（最多多少可用地址）

    MDR位数反映每个存储单元的大小，即存储字长，一位等于 \(1bit\)。

    则主存总容量为 $$ Memory = 2^{MAR}×MDR (bit) \ Memory = 2^{MAR}×MDR/8 (Byte) $$ 注意 \(8bit = 1Byte\) 8比特等于1字节

    在强调单位时，通常用Byte作为基本单位，如 \(1K = 2^{10} Byte\)

    计算机中，单位的进制采用 \(2^{10}\)作为容量大小的进制标准。

    n位地址意味着 \(2^n\)个存储单元

    总容量 = 存储单元数量 * 存储字长

    如：8×8位的存储芯片（这里的位指的是字长）

    8位指的是bit数量，所以一个字长为 \(8bit = 1Byte\) ; 有8个那就是 $ 8×1Byte = 8Byte$

    前者反应数量，后者反应字长。

    单位成本： 位价 = 总成本/总容量 ，计算每一个bit 的价钱，将容量单位转为bit。

    存储速度：数据传输速率 = 数据的宽度/存取周期

    存取周期：

    存取周期 = 存取时间 + 恢复时间

    又称作读写周期，指的是进行一次完整读写操作所需的全部时间。即两次连续独立读写操作的最小时间间隔

    \(Tm\)的的计算如下：

    命中率：当处理器或系统请求某个数据时，系统会首先在缓存中查找该数据：

    • 命中（hit）：如果数据在缓存中找到了，就称为一次命中。
    • 未命中（miss）：如果数据不在缓存中，需要从更慢的内存或存储中加载，就称为一次未命中。

    命中率的计算公式： $$ \text{命中率} = \frac{\text{命中次数}}{\text{总访问次数}} = \frac{\text{命中次数}}{\text{命中次数 + 未命中次数}} $$

    \[ 平均存取时间=命中率×命中时间+未命中率×未命中时间 \]

    前导部分-主存的基本组成¶

    一个主存可以分为三个部分：存储体，MAR，MDR

    存储元：存放一个二进制位的物理器件，存储器的最基本构件。MOS管就是开关，电容就是存储信息的介质。

    由电容存储电荷（即0/1）由MOS管接通高低平电压，实现开关作用。

    多个地址码相同的存储元构成一个存储单元。若干个存储单元的集合构成存储体（存储矩阵）。

    Text Only
    1
    存储元(地址码相同) -> 存储单元(所说的地址) -> 存储体(内存)

    存储体的总体存储结构如下图所示：

    • 蓝色的部分：是由存储元组成的存储单元，其可以理解为一个存储字，存储单元中的存储体个数即存储字长

    • 红色部分：字选线，控制一个电路上的所有存储元的MOS管开关。这也是为什么读写都是以字作为操作单位。

    • 绿色部分：数据总线，和CPU直接相连，单一一条获取一位数据的电路，称之为数据线。存储元的输出获取，即获取一个存储字。

    MAR实现取地址，主要是依靠译码器（参考数电的8位译码器）：

    通过译码器控制 \(n\) 个位的1/0，从而实现对于 \(2^n\) 个字选线（红色部分）的控制，从而读取对应位置的地址（\(2^n\)个存储单元）。

    补充，存在一个控制电路，作用为：控制MDR，MAR以及译码器。具体是：确保MAR的电信号稳定，才让译码器选择电路给出数字信号，只有数据的电信号稳定之后控制MDR给总线输出数据。即，确保每一个电路的前一个电路的电信号稳定，再开启下一步。

    片选线¶

    上头的反符号表示，只有当低电平时该信号有效。分为以下两种（功能一致）：

    • CS-Chip Select：芯片选择信号
    • CE-Chip Enable：芯片使能信号

    作用：

    • 因为一个内存条，可能有多块存储芯片，片选线的意义就在于选择哪个存储芯片
    • 控制芯片工作

    读写控制线¶

    同样是低电平有效，确定是读是写（MDR是输出数据给存储单元，还是输入存储单元内的数据）。

    分两种情况

    • 两根线：一根控制写，一根控制读

    • 当只有一根线的时候：低电平写，高电平读。

    封装结构¶

    由封装结构可以看出，一个存储芯片，需要的部分有：

    • 地址线（MAR所需）
    • 片选线
    • 读写控制线（可能有两根，参照读写控制线那里）
    • 数据线

    四个部分组成，此部分主要考察四个部分所需要的实际引脚数目。

    按照存储芯片的结构，不难看出，其按照一个类似于矩阵的结构进行存储。所以中间的部分称为：存储矩阵。

    若有1k个单元，则需要1k个字选线，不难得出需要地址线10个（\(2^{10} = 1024\)）。

    以此为例可进行推导，具体的存储空间还需要参照每个存储单元的存储字长，即存储元数量决定。

    寻址¶

    寻址我们可以按照：字节寻址、半字寻址、按字寻址·······

    存储器在编址的时候按字节编址，即1Byte为一个地址的大小，而计算机读写单位是一个字（由题目定字长）。

    若假设一个字长为4字节的存储器。

    • 对字而言，我们按字寻址，找第3个字的位置。
    • 我们要找的地址线为即0011(二进制3)。
    • 对于字节而言，相对应的实际就是找（字和字节均从0开始）第12个字节开始的地址。
    • 地址线应该为 1100 ，即左移两位。

    总结：==若按字查找，则将字的地址码，左移两位。半字左移一位。其余同理。==实际也就是靠2的倍率实现二进制的左移位数

    主存¶

    半导体存储器分为随机存储器（RAM）和只读存储器（ROM）。

    其中，RAM分为动态随机存储器DRAM和静态随机存储器SRAM。两类RAM均属于易失性存储器

    ROM是非易失性存储器。

    区别 DRAM SRAM
    名称 动态随机存储器 静态随机存储器
    存储元（核心区别） 栅极电容 双稳态触发器
    应用 主存（Memory） Cache
    刷新机制 需要每2ms再生一次电荷 只要一直供电信息就一直在

    RAM¶

    DRAM-动态随机存储器¶

    Dynamic Random Access Memory

    存储元：使用栅极电容存储信息，即本节前导内容中介绍的存储元。

    特点：结构简单，成本更低。且集成度高，功耗低。

    存在问题：利用栅极电容存储信息，即电荷作为1/0。这样的读出是一种破坏性读出（电荷损失），所以需要有一个==重写操作==，也称作再生。因而读写速度较双稳态而言更慢。

    SRAM-静态随机存储器¶

    Static Random Access Memory

    存储元：使用双稳态触发器存储信息。（仅作了解）

    双稳态：指的是

    • A高B低——1；
    • A低B高——0

    因而可以由BL，BLX，二者判断存储0/1。相较于栅极电容，其数据线需要两根。

    由BL、BLX谁输出低电平来判断除法器内存储的信息是0/1。具体如下：

    • 读：当存储为1的时候BLX会输出一个低电平（负脉冲）；当存储为0的时候，BL会输出低电平。

    • 写：同理，当需要存储0，给BLX一个高电平，BL一个低电平。当存储1，给BL一个高电平，BLX一个低电平。（按照双稳态的两种状态）

    相较于栅极电容的破坏性读出，双稳态触发器的读出操作仅仅是读取两个数据线的电平高低。因而是非破坏性读出，无需重写。因而读写速度双稳态触发器的读写速度更高（所以用于Cache）。

    特点：结构复杂，成本更高。且集成度低，功耗高。

    二者均属于，易失性存储器（不通电即会丧失信息）

    DRAM刷新¶

    再生：因为DRAM使用电容存储信息，电容内的电荷只能存储\(2ms\)，因而\(2ms\)内需要给DRAM重新再生一次。而双稳态只需要持续供电就不需要刷新。

    总结

    • 周期：默认2ms
    • 数量：一行存储单元
    • 方式：由刷新电路控制，读出一行的信息重新写入，占用一个读/写周期。
    何时刷新¶

    刷新方式：其中DRAM以行为单位，每次刷新一行存储单元。由存储芯片自行控制

    已知我们一次刷新一行，意味着假设我们由128×128的结构DRAM，那我们需要刷新128次。而我们又知道一次刷新占用一个读/写周期（存取周期），那全部刷新的时间即为：128*存取周期。假设我们一个存取周期为0.5μs，那在一个刷新周期中，我们有\(2ms/0.5μs = 4000\)个存取周期进行刷新。于是延伸出以下的刷新策略：

    1. 读写完刷新一行——分散刷新

    在这种方法当中，我们读写一行就会对这行进行刷新，所以==系统的存取周期会从0.5μs变为1μs==。也就是一个存取周期用于读写，一个存取周期用于刷新。

    1. 在2ms内集中安排刷新——集中刷新

    系统的存取周期不变，有一段时间专用于刷新。但是无法访问存储器，称之为死区

    1. 2ms内每一行刷新一次——异步刷新

    2ms每一行进行刷新，也就是每一行刷新时间间隔不超过\(2ms/128=15.6μs\)。即每隔15.6μs我们要留出0.5μs用于刷新，也就是0.5μs的死区。注意：是上一个死区结束到下一个死区结束的时间间隔为15.6μs。也就是15.6μs包含了0.5μs。

    可以理解为，是在刷新的间隔里插入了读写操作。

    通常会在CPU的译码阶段进行刷新。

    现在常用的内存是SDRAM——DDR5。区别在于传统DRAM导致了一部分延迟问题，CPU需要等待（采样DRAM的数据），SDRAM会对CPU的指令进行锁存，等到指定的时钟周期后再次响应。CPU在此期间可以进行其他操作

    行列地址¶

    原因：在工程上为了实现在存储芯片中添加尽可能多的存储单元，会导致选通线过多。为了减少译码器的选通线（过多的存储单元，增加了部署译码器选通线的数量，部署困难）采用矩阵排列。

    即，将一个译码器，增设成行地址译码器和列地址译码器。

    举例：可假设有100个存储单元，如果仅使用译码器，选通线需要接入100条。而采用行译码器和列译码器的方式仅需要各接入10条，进而极大地减少了选通线地数量。

    补充：现在工程上存在三维排列的存储单元，此处仅介绍二维矩阵排列。目的主要还是为了减少选通线的数量

    也就是传入一个MAR时，其分为两个部分，一个部分传给行地址译码器，一个传给列地址译码器。通过两根选通线，确定我们需要的存储单元（注意是存储单元）。

    但对于DRAM而言行列地址是通过相同引脚（地址线复用技术）先后两次输入的。

    地址线复用：用同一个地址码，将地址码0000 0000 分为两个部分，前半部分为对应行，后半部分为列。分别传入

    • DRAM的行列地址分两次送（地址线复用技术）
    • SRAM行列地址是同时送

    这样就行列译码器就无需8位地址线。仅需要各自所关注的4位

    而通过上述的二维结构，在刷新时，我们则可以直接通过一个行地址译码器，直接对一行的存储单元进行刷新。

    ROM¶

    只读存储器。是一种非易失性存储器，即断电之后数据不丢失的存储器。

    各类ROM¶

    • MROM

    M-Mask，掩模式只读存储器。厂家在生产时，按客户需求直接写入信息，之后==不可重写==，只能读出。

    特点：可靠性高，灵活性差，生产周期长，只适合批量定制。

    BIOS，MAC

    • PROM

    P-Programmable，可编程只读存储器。用户可以用专门的PROM写入器写入信息，写入一次后不可更改

    • EPROM

    E-Erasable，可擦除可编程只读存储器。允许用户写入，以某种方式擦除，可重复多次重写。

    按照擦除方式又有：

    • UVEPROM，UV-Ultralviolet rays。用紫外线照射擦除，擦除所有信息。（一擦擦全部）

    • EEPROM（\(E^2PROM\)），E-Electrically。可用电擦除，只能擦除特定的字。

    • Flash Memory

    闪存，基于EEPROM发展而来，在保留ROM的非易失性的前提下，可进行快速多次重写。

    注意：由于闪存是先擦除后写入的，所以其写的速度慢于读的速度

    每个存储元仅使用了单个MOS管，位密度高于RAM。（硬盘空间远大于内存空间）

    常用于：固态硬盘SSD，U盘，SD卡

    • SSD（solid state drives）固态硬盘

    由控制单元和存储单元（Flash 芯片）组成。和闪存的区别在于控制单元的不同，但存储介质类似，也可以进行多次快速重写。

    特点：速度快，价格高，功耗低。

    很多ROM也有随机存取的功能

    注意：尽管BIOS是ROM且被厂商写好在主板上，但是主板上的ROM也是主存的一部分，即BIOS也是主存的一部分。若，主板上的ROM有1KB，则实际编址当中，有0~1023的地址都分给了主板上的ROM芯片。

    主存 = 内存+主板上的ROM

    多模块存储器和双端口存储器¶

    双端口，简要了解。重点掌握多模块存储器。

    已知：存储器读写时，读写周期内有一段恢复时间（通常是存取周期的几倍）。这导致如下两个问题：

    • 对于一个多核CPU，当一个Core访问了内存，另一个Core再要访问需要等待恢复，影响效率
    • 当CPU的读写速度远大于主存，主存的恢复时间太长也导致效率瓶颈

    针对以上两个问题，多核问题，和恢复时间过长的瓶颈问题。我们分别用双端口存储器和多模块存储器解决。

    双端口存储器¶

    双端口的含义也就是提供了两个端口，可供给两个Core进行操作。

    双端口支持对同一地址单元读取，不同地址单元存取都支持

    不支持（大多针对同一地址单元）：不允许同时写入，以及一端写入一段读出。

    其有一个控制信号，用于判断逻辑暂时关闭另外一个端口。未关闭的端口正常访问，而关闭端口会延长一个较短时间后再访问。

    多模块存储器¶

    多体并行存储器¶

    多体并行存储器要求：每个模块具有相同的容量和存取速度，独立的读写控制电路，地址寄存器和数据寄存器。多个模块之间可以并行工作，也可以交叉工作。

    多体并行存储器可分为高位交叉编址与低位交叉编址。

    高位和低位的含义是：即对于地址编码是采用高位区分存储体，还是采用低位区分存储体。

    举个例子：xx00 当采用高位交叉编址，xx所表示的即为对应的存储体。而采用低位时，则是用后两位来确定对应的存储体。

    如下图：

    更为形象的是：

    当采用高位遍历地址时，是先遍历一个存储体再遍历第二个存储体。而采用低位遍历地址，则是依次遍历每个存储体当中的一个地址。在图中表示即为：高位遍历一列，而低位遍历一行。

    采用低位交叉编址的好处是：

    假设：存取周期为\(T = 4r\)而存取时间为\(r\)，即一次读写花费 \(r\) 而等待恢复的时间为 \(3r\)。

    若采用高位交叉编址，在访问完第一个地址，第二个地址仍是和前一个地址访问同一个存储体。导致我们每次都需要等待恢复。

    而低位编址避免了这个问题，即访问完第一个地址，第二个连续地址在另一个存储体中，避免了恢复时间。

    在这种情况，对于一个低位交叉编址的多提存储器而言，连续访问 \(n\) 个存储字，总共耗时为 \(T+(n-1)r\) 。而高位耗时 \(nT\)。

    为什么说仅限于这种情况？这种情况下，当n 趋于 ∞时，读一个字的效率接近于 r

    因为需要保证多体的多（取几个体的问题）：m个存储体，可以做到\(m*r \ge T\) 才可以实现无需等待恢复。也就是要 $$ m \ge \frac{T}{r} $$ 这种存取方式，称为Pipeline——流水线（宏观上并行，微观上串行）。

    单体多字存储器¶

    单体多字存储体，相当于在多体并行存储体的基础上，删去了独立的读写电路，数据寄存器和地址寄存器。

    多个模块共用上述的三个部分。

    特点：

    • 每个存储单元存储\(m\)个字，总线宽度也为\(m\)个字，一次并行读出\(m\)个字。这里的m是模块数量。
    • 在一个存取周期内，从同一地址取出m个指令，逐条送入CPU执行。
    • 工作效率较高，但仅在指令和数据连续存放时有效。一旦分开存放，提升不明显。

    存储器与CPU的连接¶

    主存扩展¶

    为什么要进行主存扩展？¶

    单张内存芯片的容量是有限的（比如 \(8K \times 8\) 位）。当 CPU 需要的存储容量（如 \(64K \times 32\) 位）超过单片能力时，就需要将多张芯片拼接起来。

    • 地址线（A）：决定有多少个房间（控制“字数”）。
    • 数据线（D）：决定每个房间有几扇窗（控制“位数”）。

    64K是存储单元的大小（单位是bit），位数是存储字长的长度。二者计算后才能得到整个存储空间大小。

    三大扩展¶

    位扩展（增加数据宽度）¶

    什么时候用：满足CPU的机器字长需求，也就是匹配CPU的数据总线宽度。扩充存储字长

    在实际生产中，内存条都是生产出 \(\times 4\)位的存储芯片，再去用位扩展，使得能够满足对应CPU的数据总线宽度。

    连接规则：

    • 地址线：所有芯片的地址线并联，同时接收 CPU 的同一个地址。
    • 控制线（片选 \(\overline{CS}\) / 读写 \(\overline{WE}\)）：所有芯片的片选线并联，同时开、同时关。

    • 数据线：各自独立，分段连接到 CPU 的数据总线上（例如：芯片1连 \(D_0 \sim D_3\)，芯片2连 \(D_4 \sim D_7\)）。

    • 物理直观：把两张纸并排贴在一起，让纸张变得更宽。

    这里我们以一个1位存储体为例，因为其只有一位的数据，所以对于数据线的使用极不充分。

    可见，八位数据线只利用了一个。这个问题是源于存储体可以存储的字长不足。

    因而我们要充分利用数据总线，则将八位用八个存储体全都连接上，实现了充分利用，进而实现了位扩展。由地址总线的信息来控制N个存储体（扩展几个控制几个）来进行读写（读写操作仍以一个字（这里是八位）作为最小操作单位）

    字扩展（增加存储单元数量）¶

    什么时候用：芯片的位数够用，但存储空间不够（例如：用 \(8K \times 8\) 位的芯片拼出 \(24K \times 8\) 位）。

    连接规则：

    分为线选法和片选法（接入一个非门或译码器）

    • 地址线：CPU 的低位地址线并联到所有芯片上。高位地址线用来作为“片选信号”，决定哪一个芯片工作。
    • 数据线：所有芯片的数据线并联到 CPU 数据总线上（因为它们不会同时发光）。
    • 控制线：读写线并联；片选线 \(\overline{CS}\) 独立，由高位地址线控制（因为给0才enable，译码器输出那里有个非门）。

    考虑存储空间不够时，如何扩展存储空间。对于字扩展，则是通过片选器来控制读写哪一个存储体。尽管存储空间得到了扩展，读写单位还是一个存储芯片。

    但需要与位扩展的数据线相对的，这里需要存储体的地址引脚少于CPU的地址引脚数量。（之前是数据线少于）

    CPU的地址引脚也分为了两个部分：

    • 低位控制存储体的地址
    • 高位则是控制译码器进而控制要读写的存储体

    CPU的地址总线数量 = 存储体自身的地址接口数量 + 译码器占用高位

    ！注意这个等式未必严格相等。仅用于理解。

    这里仅展示了片选法。需要注意的是，选择地址的地址线具体的地址码，要视接入译码器和存储体的地址线判断。可能存在\(A_{15}\)和\(A_{13}\)接入不管\(A_{14}\)的情况。

    区别：

    线选法 片选法
    n条线——n个状态 n条线——\(2^{n}\)种状态
    电路简单 电路复杂
    地址空间不连续 地址空间可连续

    “地址空间不连续”的含义——各芯片占据的地址段是分散、断裂的，无法合并成一个完整的大段连续地址。

    管两个存储体，要用01或者10，这个情况导致了00和11被割裂了；而译码器可以把全部的位置都用上

    磁盘¶

    外存储器¶

    外存储器既可以作为输入设备，也可以作为输出设备。（兼具IO特性）读写的单位均为1bit，且读写不可同时进行

    磁盘组成¶

    存储区域¶
    • 磁头数：记录面数
    • 每个面有若干磁道（每个面上的一个同心圆）
    • 磁性材料是一圈一圈涂的（即为磁道）
    • 也存在某些面不去读写作为其他面的替代
    • 柱面数：面上的磁道数
    • 柱面，是由盘组的若干记录面上的同编号磁道构成
    • 扇区数（也称作块）：一条磁道上的扇区数量。
    • 扇区，就是同心圆（磁道）被分成多个部分，每个部分即为扇区
    • 扇区实则不是几何理解，实际为磁头按照磁道扫过的弧，从微观看像扇区，从宏观看实际像一段弧线
    • 主机对磁盘进行读写的操作，都是以扇区为单位
    硬盘存储器¶

    驱动器：磁头组件和盘片组件

    控制器：硬盘和主机的接口。主流的接口标准：SATA SCSI IDE

    可以在磁盘的正反片分别涂上磁性材料，要注意记录面是夹住磁头的，因为一个磁头写两面好控制成本。

    磁盘性能指标¶

    容量¶

    格式化：按特定格式记录所能记录的信息的总量，用作非存储用途的容量

    非格式化：常规所用的存储容量

    记录密度¶

    道密度：沿磁盘半径方向单位长度上的磁道数。

    位密度：指的是磁道上单位长度能记录的二进制代码位数（因为周长原因以及每个磁道的存储信息大小保持一致，越靠近圆心的位密度越大）

    面密度：道密度*位密度

    平均存取时间¶

    先寻道，再找扇区，最后传输。三个时间的总和，传输需要磁头划过整个扇区（弧线）。传输和找扇区都以磁盘转速来计算

    有的题目还需要加上，磁盘控制器的延迟

    数据传输率¶

    传输率，也就是单位时间内传输的字节数

    跟传输过程一致，需要画弧线，所以公式位磁盘的转速和磁道的容量的乘积。

    磁盘地址¶

    分为四个部分：驱动器号（哪个硬盘），柱面号（对应的磁道），盘面号（激活对应的磁头），扇区号（磁道的特定区域）

    题目通常考察需要确定某个扇区需要多少信息，具体由每一个部分的数量来定（位数二进制转十进制大小>=实际数量）

    工作过程¶

    寻址，读盘，写盘。三个操作对应一个控制字，工作时，取指再执行

    RAID—磁盘阵列¶

    RAID全称为Redundant Array of Independent Disks，中文为独立磁盘冗余阵列。

    为一种将多个硬盘驱动器组成一个逻辑单元的数据存储虚拟化技术，以提高容量，读写速度以及数据可靠性。

    RAID0¶

    RAID0 是一种追求极致容量和读写速度的磁盘阵列。其的实现原理是将多个磁盘均用于读写和存储，一个数据被拆分成多个数据写入磁盘阵列当中。

    优势：n个磁盘均用于读写，所以读写速度为单个硬盘的n倍；同时因为数据被拆分n份写入，容量也达到单个硬盘的n倍。

    弊端：因为一个数据的某个bit位都只存于一个盘中，所以只要一个盘损坏数据将无法复原。数据可靠性极低

    RAID1¶

    RAID1 是一种追求极致的可靠性的阵列。其原理是多个硬盘用于读取同一个文件，起到多重备份的作用。

    优势：多个文件读取同一个文件（完整读取），所以尽管有多个磁盘损坏，仍能恢复数据，可靠性高

    弊端：多个文件都读取同样的数据，所以容量和读写速度仍是一个磁盘的规格

    RAID10¶

    RAID10并非一个全新的独立阵列，而是基于RAID1和RAID0的的阵列方式。其实现原理是先RAID1再RAID0（所以实际是存在RAID01的，也就是先0再1）。其实现的原理是将n个磁盘拆分个m份，用于实现RAID1阵列，这m个阵列中都至少有2磁盘；再将这m个阵列，又再一次组成一个RAID0阵列。

    优劣：并没有很明显的优劣，相较于RAID0，对于每一个拆分后的数据都有备份。相较于RAID1每一个数据都已经进行拆分，所以存储数据的容量和速度均有m倍的提升

    Q：为什么不使用RAID01呢？

    A：因为RAID01是先使用RAID0组成阵列，再用这些阵列组成RAID1阵列。这样的话，当我们想对设备进行升级的时候即对于容量和读写速度提升。就需要对每个RAID0阵列都添加至少一个盘（而且每个阵列添加的盘应该相同），而不能像RAID10一样只需要添加一个阵列（甚至这个阵列中仅有两个磁盘）。

    不常用RAID¶

    RAID2/3/4 均是针对不同的场景设计的阵列方案，因而在实际使用时会具有很大的缺陷。所以很少使用

    RAID2¶

    最少需要3个磁盘。读写的时候需要对数据进行实时编码，分段写入不同的硬盘。得到的数据比原始数据大，RAID2模式在读写时需要实时校验数据。使用的校验算法比较复杂，硬件开销大。

    RAID3¶

    RAID3是在RAID2的基础上发展而来的，采用的算法更为简单。RAID3也需要三个磁盘，两个用于分段写入数据，而一个盘用于存储校验数据。（由于进行读写操作的时候都会访问校验盘，这使得校验盘极易长时间高负载工作），校验盘如果损坏所有数据丢失。

    RAID4¶

    RAID4同样采用，一个盘用于校验盘用，不同的是RAID3采用bit分割存储数据，而RAID4则用数据块（数据块大小由系统决定）分割存储数据。因为数据块比bit位大的缘故，小文件的写入RAID4更快。RAID4相较于RAID3非校验盘损坏恢复的概率更低。

    常用RAID¶

    RAID5¶

    多硬盘并联，其中一个盘的容量用于存储校验数据。RAID5的原理和RAID3原理类似，同样至少需要3个磁盘，但是RAID5将校验的数据分散在每一个盘中，如果一个盘的数据损坏，可依靠其他盘中的数据配合校验信息恢复。RAID5读写速度与RAID0相近，但不及RAID0；因为各个盘中会占据一个盘的校验数据，所以可用容量=总容量-单个磁盘的容量（每个盘大小一致）。

    RAID6¶

    多硬盘并联，其中两个盘的容量存储校验数据。因为需要两个盘的容量存放存储校验信息，RAID6则至少需要4块硬盘。原理上和RAID5类似。RAID6会使用两种不同的校验算法，任意坏两个盘都能够实现数据恢复，所以RAID6数据安全性非常高。相较于RAID5，因为比RAID5多使用一种校验算法，校验数据量比RAID5大，计算量也比RAID5大，所以读写速度不如RAID5。

    URE¶

    URE指的是硬盘先天缺陷，机械硬盘无法避免不可恢复性读取错误。也就是在读取一定量的数据时，盘可能出现一个无法读取的错误。（大概是每12T可能读取1个）。因为这个缺陷，所以RAID6比RAID5更安全一点。解释：当RAID5出现这个错误，RAID5就需要重新建立阵列，导致所有的盘都在长期高负荷工作，很容易出现恢复过程中其他盘损坏进而导致数据无法恢复。RAID6还有错一个的容错

    擦除¶

    SSD以块作为擦除基础单位。具体原因如下：

    写入时只能做到把某个电容从1（无电子）转化为0（有电子）。而不能逆向改写，因而在需要修改数据的时候，需要先进行擦除，才能改写数据。

    而具体的改写操作，称作写入放大（Write Amplification）

    • 例如，只是想写入 4KB 的数据，但因为目标块里有其他数据，SSD需将原块的数据连同新数据写入到其他块当中，原块的数据会被擦除（也就是新块变为了新的存储位置）。结果系统实际写入的数据量，远大于原本想写的数据量。
    • 本来的逻辑块号和原块是相互映射的，经过写入放大之后，翻译层会修改映射关系，使得逻辑块号和新块映射

    这也是为什么闪存用久了寿命会损耗、速度会变慢的底层物理原因

    同时这种写入的问题，会导致SSD呈现出写慢读快的特性

    随机访问¶

    系统给定一个逻辑地址时，闪存翻译层可以通过电路迅速定位到对应的物理地址。

    与机械硬盘相比¶

    SSD 机械硬盘
    读写速度快，随机访问性能高，用电路控制访问位置。 靠移动磁臂，旋转磁盘控制访问位置，有寻道时间和旋转延迟
    安静无噪音，耐摔，能耗低，造价高 有噪音，不耐摔，能耗高，造价低
    擦除多次会损坏块 扇区不会因为多次写入坏掉

    磨损均衡技术¶

    因为影响使用SSD寿命的主要是擦除写入的方式。所以将擦除平均分布在各个块上，以提升使用寿命。

    动态磨损均衡¶

    写入数据时，优先选择累计擦除次数少的块

    静态磨损均衡¶

    SSD检测并自动进行数据分配，让读多写少的数据存储到老块中，新块承担更多写任务

    Cache¶

    主要用于缓和主存和CPU直接的速度差异。

    局部性原理¶

    空间局部性：未来要使用的信息，很可能与当前使用的信息在存储空间上是邻近的

    时间局部性：未来要使用的信息，很可能是当前正在使用的

    基于局部性原理，可将CPU目前访问的数据的“周围”数据提前放入cache中。

    界定周围¶

    将主存的存储空间“分块”，以块为单位（如一个列表的一个下标元素的大小），主存和Cache之间进行数据交换

    以1KB为例进行分块¶

    假设一个主存为\(4MB\)，\(4M = 2^{22}\), \(1K = 2^{10}\) 。则总共可以分作 \(2^{12}\)个块，块号可以用 12 位二进制表示，块内地址可以用 10 位二进制表示。

    在操作系统中，一个块也被称作 页，页面，页框。Cache中的块也可以称作行

    命中率¶

    指的是CPU想要访问的数据，已经在Cache中的比率。

    计算公式为：

    \(t_c\) 为CPU访问Cache所需的时间，\(t_m\) 是CPU访问主存所需的时间，H为命中率。 $$ t = Ht_c+(1-H)(t_c+t_m) $$ 也就是命中率×访问Cache的耗时，加上缺失率×（访问cache和主存的耗时）得到总耗时。

    如果CPU同时访问Cache和主存，则公式变为 $$ t = Ht_c+(1-H)t_m $$

    映射关系¶

    当CPU访问Cache没有找到所需的数据，则会直接访问主存。（也存在并行情况）而被访问的块会被立即调用到Cache中。

    而因为主存块会被放入到Cache的任意位置。所以需要一种映射关系来帮助CPU区分Cache 和 主存的数据块的对应关系。

    全相联映射¶

    主存块可以放在Cache的任意位置

    并且通过标记和有效位来确定映射关系。

    • 标记表示Cache块所对应的主存块。
    • 有效位用于区分标记0代表主存块还是未标记（未标记的块有效位和标记同样为0）

    这里的标记写作了十进制，实际上按照前文所说的分块方法，这里应该是完整的主存块数。如，之前的 \(1KB\) 分 \(4MB\) 这里的主存块数则有 \(2^{12}\)个，则标记为 12位二进制数

    缺点：

    • 查找标记是三个方法里最慢的（另外两个方法先找块再看标记对不对）
    • 可能需要遍历所有的行

    直接映射¶

    每个主存块只能放到一个特定位置：Cache块号 = 主存块号 % Cache总块数

    优点：速度三个方法最快

    缺点：其他块有空闲的情况下，Cache块号相同的主存块，不能使用，必须由读块覆盖掉旧读块。

    • 空间利用不充分
    • 命中率低（空间利用不充分天然导致命中率低，所以全相联的优点则是命中率高）

    标记并不直接采用主存块号，用了标记加索引的方法。

    标记拼接索引 = 主存块号。可以利用主存块号的末尾n位迅速找到其在Cache中的位置。

    tip：用主存块号找Cache中的位置，主要原因是，CPU在访问信息时依旧以主存地址作为访问信息的。只不过会优先看看Cache中是否已有对应的主存块的信息。

    组相联映射¶

    将Cache块分为若干组，每个主存块可以放到特定分组中的任意位置

    组号 = 主存块号 % 分组数

    本质还是类似于直接映射。只不过将索引改为了组号，在过程上和直接映射一致，先用组号（索引）找Cache块，再通过标记和有效位确定是否是索要访问的主存地址。

    优点：上述两种方法的折中，速度较快的同时，命中率不低。

    替换算法¶

    Cache很小，主存很大的情况下，出现Cache的满了的情况下，怎么替换才能提高命中率。

    随机算法RAND¶

    核心思想：若Cache已满，则随机选择一块替换。

    优点：实现简单

    缺点：没有考虑局部性原理，命中率低，实际效果不稳定。

    先进先出FIFO¶

    核心思想：若Cache已满，优先替换最先被调入的块

    优点：实现简单

    缺点：依旧没有考虑局部性原理

    且会出现抖动现象：块频繁换入换出。

    近期最少使用LRU¶

    核心思想：为每一个块设置一个计数器，记录每一个块在多个访问操作中未被访问。当出现需要替换的情况时，优先替换次数最多的块

    计数器的最大值受限于Cache块数，且Cache装满后计数器一定不重复。

    优点：基于时间局部性考虑。命中率高。

    • 但在频繁访问主存块的数量>Cache行数的时候，也易出现抖动。

    最近不经常使用LFU¶

    核心思想：同样设置了一个计数器，记录每个Cache块被访问的次数。需要替换时，优先替换次数最少的。

    相较于LRU，会出现计数器相同的情况，这时可按照FIFO或者行号递增策略（优先淘汰小行号）进行选择

    按照曾经被访问的主存块，未来不一定被用到的想法考虑。因而没有遵循局部性原理，命中率不如LRU

    Cache写策略¶

    为了保证CPU修改了Cache的数据副本（Cache中的数据都是从主存当中复制的）后和主存数据母本的一致性。

    写命中¶

    全写法¶

    write-through，又称作写直通法。当CPU对Cache写命中时，同时写入Cache和主存中。一般使用写缓冲（Write buffer）

    优点：数据一致性

    缺点：访存次数增加，速度慢。

    Write buffer

    在此处，写缓冲会将写命中的内容进行累计缓存。待到CPU进行非写操作时，控制电路会将buffer中的内容写入到主存中。但如果写操作频繁，可能会导致写缓冲饱和而发生阻塞。

    写回法¶

    当CPU对Cache写命中时，只修改Cache中的内容，当Cache块被换出的时候才会写回主存。

    优点：减少了访存次数

    缺点：存在数据不一致的隐患

    写不命中¶

    写命中考虑的是CPU所需写的块在Cache中，写不命中则反之。

    写分配法¶

    写不命中时，把主存的块先调到Cache中，再进行修改。一般搭配写回法（Cache换出时改主存）使用。

    非写分配法¶

    写不命中时，不把块调入到Cache中，直接写入主存。搭配全写法使用。

    补充¶

    在Cache 与 主存之间常采用，“写回法和写分配法”（修改都在Cache中进行），也就是在更快的一层进行写操作。

    而在多级Cache之间常采用，“全写法和非写分配法”（修改在上一层的存储内完成），在容量更大的一层完成。
