    概述¶

    计算机有两个重要的部分：软件和硬件，二者相结合组成我们熟知的计算机。而计算机组成原理主要介绍的是计算机的硬件。这里我们简单给出一点软件的相关概念。

    软件¶

    系统软件¶

    用于管理整个计算机系统的程序（操作系统，DBMS，各类驱动），负责管理硬件资源，并向上（user & application，用户和应用层）提供基础服务。

    应用软件¶

    定义：解决某个领域的问题所编制的程序

    软件性能的发挥离不开硬件的支持。

    一个功能的实现，即可以通过软件实现，也可以通过硬件实现则称软件和硬件的逻辑功能等价。

    硬件¶

    现在的计算机主要是按照冯诺依曼架构设计，而冯诺依曼架构指的是：

    • 存储器（Memory Unit）
    • 控制器（Control Unit）
    • 运算器（Arithmetic/Logic Unit）
    • I/O设备（Input/Output Device）。（这里的I/O设备，指输入和输出两个设备）

    由这五种设备组成的一台计算机，我们都可以称之为冯诺依曼架构，现代计算机将控制器和运算器结合为一个CPU（central processing unit）。

    发展历史（已删）¶

    四代计算机¶

    电子管时代

    第一代计算机，是用电子管作为逻辑单元，时代原因，那个年代只能生成出电子管这样表达 0/1 的逻辑单元。

    这个时代的计算机特点：体积超大，耗电量超大，成本高，运算慢

    使用机器语言进行编程（即二进制编码 0/1），所以那时候的程序员主要依靠穿孔纸带或者穿孔卡片进行编程。

    晶体管时代

    第二代计算机，采用晶体管作为逻辑单元，正如之前所说，随着工业的发展和设计的进步，可以生产出体积更小的逻辑单元。于是晶体管替代掉了电子管。得益于电子管更小的规格，使得电路可以变得更为复杂，计算速度得到有效提升，计算机的体积也开始缩小。

    特点：计算机软件得到发展，出现出现高级语言和其编译程序，操作系统开始有了雏形。

    中小规模集成电路时代

    第三代计算机，开始采用集成电路作为逻辑单元。

    这个时期计算机仍然主要用于科学计算，但是高级语言迅速得到发展。开始有了分时操作系统。

    说句题外话，集成电路实际是集成了大量的晶体管。

    超大规模集成电路时代

    第四代计算机，集成电路规模更大（指的是集成电路当中集成了更大量的晶体管）。

    PC（个人电脑），微处理器，各类操作系统，在这个时代诞生

    并行、流水线、高速缓存、虚拟存储器等概念在这代计算机实现

    硬件总结：

    发展阶段 时间 逻辑元件 速度 (次/秒) 内存 外存
    第一代 1946-1957 电子管 几千-几万 汞延迟线、磁鼓 穿孔卡片、纸带
    第二代 1958-1964 晶体管 几万-几十万 磁芯存储器 磁带
    第三代 1964-1971 中小规模集成电路 几十万-几百万 半导体存储器 磁带、磁盘
    第四代 1972-现在 大规模、超大规模集成电路 上千万-万亿 半导体存储器 磁盘、磁带、光盘、半导体存储器

    元件的发展¶

    摩尔定律：当价格不变，约每隔18个月，集成电路上可容纳的晶体管数量提升一倍，性能也提升一倍。

    微处理器的发展：也就是CPU 常听见的32位，64位，指的是计算机进行一次整数运算所能处理的二进制的位数

    计算机的组成¶

    冯诺依曼机¶

    指的是符合冯诺依曼架构的计算机。由五个组件组成的计算机，称之为冯诺依曼机。

    • 五大组成部分： 1. 运算器（ALU）： 完成算术和逻辑运算。 2. 控制器（CU）： 指挥各部件协同工作，从存储器读取指令。 3. 存储器（Memory）： 存放程序和数据。 4. 输入设备： 将外部信息输入计算机（如键盘、鼠标）。 5. 输出设备： 将计算机的处理结果输出（如显示器、打印机）。

    基本工作方式：控制流驱动方式。

    特点

    • 采用存储程序的工作方式
    • 计算机硬件系统由五个部件组成
    • 指令和数据以同等地位存储在存储器中，形式上无区别，但计算机能够区分

    • 计算机主要通过执行阶段（时机）来区分：

      • 取指周期：从内存中取出的二进制流送往 IR（指令寄存器），此时被识别为指令。
      • 执行周期：从内存中取出的二进制流送往 ACC/X（运算器），此时被识别为操作数（数据）。

    • 指令和数据都用二进制表示

    • 指令由操作码和地址码组成
    • 以运算器为中心（现代CPU是运算器+控制器）

    存储程序：将事先编制好的程序与原始数据送入主存储器（内存）后才能执行，计算机可以按照程序的顺序依次读取指令并执行相应的操作直至执行结束，过程中无需人工干预。

    现代计算机：以存储器为中心，CPU与主存（内存）组成主机，而I/O与辅存（存储空间）组成I/O。

    状态寄存器PSW，通用寄存器GPRS，只有为汇编程序员可见。

    寄存器的“透明性”（按用户可获取/访问定义）：

    • 不透明（用户可见/可获取）：指程序员可以通过指令直接访问或间接修改的寄存器。
    • 包括：PC（通过跳转指令修改）、ACC、GPRs、PSW、SP。
    • 透明（用户不可见/无法获取）：指由硬件逻辑自动控制，程序员无法在指令中指明操作的寄存器。
    • 包括：MAR、MDR、IR。其目的是保护数据通路的原子性和硬件实现的灵活性。

    五个部件¶

    主存储器¶

    可分为主存储体，和两个寄存器：MDR（D:Data）与MAR（A:Address）

    MAR——Memory Address Register，存储地址寄存器（用于寻址，往哪儿写，从哪儿读。其位数可反应最多可寻址的存储单元个数）

    MDR——Memory Data Register，存储指令寄存器（写入什么，读出什么。位数通常等于存储字长）

    Memory && Storage：

    • Memory（主存）：通常指 RAM（易失性）和存放引导程序的 ROM（非易失性，仅读）。
    • Storage（外存/辅存）：指硬盘（SSD/HDD）、U盘等。CPU 不直接从 Storage 取指令，必须先调入 Memory。

    存储单元：存储体可分为多个存储单元（存储的最小单位），地址所指的位置代表着一个存储单元。

    存储字：每个存储单元中存储着一串二进制码，这个二进制码，称为：存储字（word），其长度称作存储字长。

    存储元：存储二进制的电子元件，即存储每个0/1的元件是存储元。

    每个存储元存储1bit，一个0或者一个1。一个字=16bit，即字长有16位。

    小结：

    名称 定义
    存储单元 存储的最小单位
    存储字 存储单元存储的内容（二进制码）
    存储字长 存储字的长度
    存储元 存储二进制码的一位内容的电子元件。（存储1bit）

    相联存储器：即可以按地址寻址，也可以按内容寻址。与传统存储器区别，也称作按内容寻址存储器。存储单元存储着两种数据，一种是OP+Ad，操作码和地址码。另一种是纯Data。

    CPU¶

    运算器¶

    用于实现算术运算和逻辑运算的设备。（算术运算：四则运算 && 逻辑运算：与或非）

    其核心为算术逻辑单元（Arithmetic and Logic Unit, ALU）。运算器包含若干个寄存器，用于暂存操作数和中间结果，介绍其中主要的三个：

    • 累加器ACC：用于存放操作数或者运算结果

    • 乘商寄存器 MQ：在乘除操作中，存放操作数或运算结果

    • 操作数寄存器 X：通用的操作数寄存器，用于存放操作数。

    控制器¶

    CU——Control Unit：控制单元，分析指令，给出控制信号。

    IR——Instruction Register：指令寄存器，存放当前执行的指令。

    PC——Program Counter：计数器，负责存放下一个指令的地址和在执行下个指令时自动对指令地址+1。

    一条指令的执行：由PC指向下一条指令的地址，通过IR取出指令存储，CU负责分析和执行指令。

    PC和IR的工作合并称为：取指；CU部分则称作：执行。

    ALU：组合逻辑电路，负责执行算术运算（如加减乘除）和逻辑运算（如与或非、位移），不具备存储功能。

    CU：调度中枢。根据指令寄存器（IR）中的操作码进行译码，并在特定的时序信号下，向全机发出控制命令（微操作序列）。

    寄存器组（GPRs）：极速暂存空间。由于 CPU 访问主存速度远慢于运算速度，寄存器组用于存放当前指令正在使用的操作数和中间结果。

    Cache：介于 CPU 与主存之间的小容量存储器。利用程序访问的局部性原理，存放最近经常使用的指令和数据，减少 CPU 访存等待时间。

    PSW：记录 ALU 算完后的状态（是否溢出、正负等）。是物理上紧邻 ALU 的存储器件。当 ALU 完成运算，其产生的状态信号（如进位 C、溢出 V、结果为零 Z、负号 S）会瞬时锁存在 PSW 中

    工作过程¶

    计算机的工作过程从用户编写的源代码开始。源代码首先被编译器翻译成汇编语言，再由汇编器翻译为机器语言（一个.o文件，称作目标模块），通过链接器将其他被引用的模块（如一些标准函数）被链接器链接成一个统一模块。形成由操作码（OP）和地址码（Ad）组成的指令序列，具体流程如下：

    编译 (Compilation)：将高级语言（如 C++）转换为汇编语言。这是一种多对多的逻辑转换，包含复杂的语法分析和代码优化（一行代码可能变多行指令）。

    汇编 (Assembly)：将汇编助记符转换为机器码。这是一种一对一的同义词替换，将 MOV 等符号直接映射为二进制编码。

    这些指令存储在主存（Main Memory）中，CPU得到执行命令，便会开始如下工作。

    程序执行时：

    1. 程序计数器（PC）记录下一条指令的地址，并通过存储地址寄存器（MAR）向主存请求指令。(PC)→MAR，
    2. 主存根据MAR中的地址读取指令从存储器(M)中读取指令，将其加载到存储数据寄存器（MDR）。M(MAR)→MDR
    3. MDR会将其传递到指令寄存器（IR）中暂存。(MDR)→IR
    4. 将IR中的操作码部分(OP)传给控制单元（CU）进行分析，确定指令类型并生成相应的控制信号。OP(IR)→CU

    (PC)→MAR，M(MAR)→MDR，(MDR)→IR，OP(IR)→CU。M-从存储器中读，OP-传递操作码

    如果指令包含地址码：

    1. CU会将IR中存储地址码送入MAR。Ad(IR)→MAR

    2. 一般情况：MAR通过主存获取这个地址的存储字，传给MDR。M(MAR)→MDR - 在存数的情况下，是先由ACC将结果传给MDR，而非M(MAR)。(ACC)→MDR

      • 最终都是由CU控制主存，将MDR的结果按照MAR的地址写入主存。(MDR)→M(MAR)

    3. 操作数经MDR传递至累加器（ACC）或通用寄存器（X）。(MDR)→ACC/X - 进行加减运算时，操作数直接送入 \(X\)，与 \(ACC\) 中的原值完成运算；(MDR)→X, (ACC)+(X)→ACC

    • 进行乘法运算时，\(ACC\) 中的被乘数先移至 \(X\)，新取出的乘数经 \(MDR\) 送入 \(MQ\)，结果的高低位分别存于 \(ACC\) 和 \(MQ\)；(ACC)→X, (MDR)→MQ, 0→ACC, (X)*(MQ) → ACC,MQ

    • 乘法 (Multiplication)：

      1. \((ACC) \rightarrow X\) (被乘数入 X)
      2. \(M(MAR) \rightarrow MDR \rightarrow MQ\) (乘数入 MQ)
      3. \(0 \rightarrow ACC\) (清零累加器)
      4. \((X) \times (MQ) \rightarrow ACC, MQ\) (高位在 ACC，低位在 MQ)

    • 进行除法运算时，\(ACC\) 存放被除数，新取出的除数送入 \(X\)，运算后的商存放在 \(MQ\)，余数保留在 \(ACC\)。(MDR) → X, (ACC)÷(X) → MQ...ACC

    • 除法 (Division)：

      1. \(M(MAR) \rightarrow MDR \rightarrow X\) (除数入 X)
      2. \((ACC) \div (X) \rightarrow MQ \dots ACC\) (商存入 MQ，余数存入 ACC)
    1. 接着，CU指挥算术逻辑单元（ALU）执行运算。

    程序计数器（PC)提供指令地址 → MAR 访问主存 → MDR 取出指令 → 指令寄存器（IR) 保存指令 → 控制器译码产生控制信号 → 从 通用寄存器（GPR） 或主存取操作数 → ALU 执行运算并更新 标志寄存器（PSW） → 结果写回寄存器或存储器 → 根据指令或 PSW 更新 PC → 进入下一条指令周期。

    例如加法运算中，X和ACC的内容被送入ALU，计算结果返回ACC暂存。若为乘法运算，乘商寄存器（MQ）会参与存储中间结果。运算完成后，结果可通过MDR写回主存。最后，PC自增，指向下一条指令的地址，循环此过程。

    之前所提及的软硬件之间的逻辑功能等价：程序员编写的代码（软件）描述了计算目标，而硬件通过执行指令实现相同的逻辑结果。因而，软件的实现离不开硬件的具体支持，指令的格式和执行方式需要一个标准化的接口来协调两者。软件能做到的硬件也能做，反之同理。

    这个标准化结构即是：ISA（Instruction Set Architecture）指令集体系结构。

    ISA定义了一台计算机支持的所有指令集合，包括操作码的类型（如取数、加法）、地址码的寻址方式（如直接寻址、寄存器寻址）以及硬件如何响应这些指令

    计算机层次结构¶

    层级 名称 描述
    M0 微程序机器层 最低层，由硬件和微代码组成，负责解释机器指令。直接控制 CPU 的数据路径，执行寄存器、算术逻辑单元（ALU）等硬件组件的微操作。通常以固件或硬连线逻辑实现。
    M1 机器语言层 本机机器指令层（如操作码），由 CPU 直接执行。这些指令是特定处理器架构（例如 x86、ARM）的低级指令，直接操作寄存器和内存。此层程序为二进制或汇编代码。
    M2 操作系统层 操作系统提供进程管理、内存管理、文件系统和输入/输出操作等服务。它抽象硬件细节，通过系统调用为上层提供与硬件交互的接口。
    M3 汇编语言层 使用汇编语言，为机器代码（M1）提供人类可读的表示形式。使用助记符（例如 MOV、ADD），通过汇编器翻译为机器代码。提供低级控制，同时比二进制稍抽象。
    M4 高级语言层 最高层，使用高级语言（例如 C++、Python、Java）编写程序。这些语言与平台无关，关注问题解决，提供变量、函数、对象等抽象。编译器或解释器将其翻译为较低层（M3 或 M1）。

    解释¶

    • 微程序机器M0（微程序机器层）： 由硬件直接执行微指令
    • 传统机器M1（传统机器语言层）： 这一层包含处理器的指令集体系结构（ISA），执行二进制机器命令，由微程序解释机器指令系统。
    • 虚拟机器M2（操作系统层）： 操作系统作为硬件与软件之间的中介，管理资源并提供抽象。这层实际上已经到了软件的层次，可以称作混合层，因为其不仅包含机器指令，还有操作系统自身定义和解释的软件指令，称作“广义指令”，即系统调用（system call）
    • 虚拟机器M3（汇编语言层）： 用汇编程序翻译成机器语言程序，汇编语言为机器代码提供符号化表示，编程比二进制稍简便。每个助记符对应一条机器指令，由汇编器翻译为 M1 层代码。
    • 虚拟机器M4（高级语言层）： 高级语言注重程序员生产力和代码可移植性，抽象硬件细节，允许编写复杂程序而无需关注底层架构。编译器将高级代码翻译为汇编（M3）再翻译为机器代码（M1）；或直接翻译为机器代码（M1）；解释器则边译边执行。（注意：编译和解释的区别，前者一次编译多次使用，后者需要边译边跑）

    计算机性能指标¶

    存储¶

    MAR位数反映存储单元的个数（最多多少可用地址）

    MDR位数反映每个存储单元的大小，即存储字长，一位等于 \(1bit\)。

    则主存总容量为 $$ Memory = 2^{MAR}×MDR (bit) \ Memory = 2^{MAR}×MDR/8 (Byte) $$ 注意 \(8bit = 1Byte\) 8比特等于1字节

    在强调单位时，通常用Byte作为基本单位，如 \(1K = 2^{10} Byte\)

    计算机中，单位的进制采用 \(2^{10}\)作为容量大小的进制标准。

    存储字长与机器字长的区别¶

    存储字长，指的是主存存放的位数；与此相对的，机器字长，指的是CPU一次能处理的位数，受CPU内部的寄存器影响（主要受通用寄存器GPRs 和 ALU）

    机器字长和机器码¶
    • 与机器码长度（指令字长）一致：IR 的宽度。为了完整存放一条指令以便译码。
    • 与机器字长一致：ACC、通用寄存器（GPRs）、ALU 内部通路。为了匹配单次整数运算的精度。

    注意：同一程序在不同机器上运行，指令条数可能不同。原因包括：

    1. ISA（指令集）差异：如 CISC（复杂指令集）一条指令能做的事，RISC（精简指令集）可能需要多条。
    2. 寄存器数量：寄存器少会导致产生更多的访存指令（Load/Store）。
    3. 机器字长：字长短的机器处理大数时需要多次拆分计算。

    CPU¶

    • CPU主频：CPU内部数字脉冲信号震荡的频率。每一个震荡的周期称作：CPU时钟周期，单位：微秒，纳秒。
    • \(主频（时钟频率） = \frac{1}{CPU时钟周期}\\\) 单位是 HZ
    • CPI（Clock cycle Per Instruction）：执行一条指令所需要的时钟周期。
    • 一条指令的执行耗时为： $Time = CPI×CPU时钟周期 $，在对比两个机器的时候，一般用二者对同一个程序的耗时判断，所以需要知晓CPI, CPU时钟周期，指令条数才能判断。尽管是相同的程序，在不同的ISA上也会有指令条数差异
    • IPC（Instruction Pre Clock cycle）：每个时钟周期运行多少个指令。
    • IPS（Instruction Per Second）：每秒可以执行的指令数
    • \(IPS = \frac{主频}{平均CPI}=\frac{1}{平均CPI*CPU时钟周期}=\frac{1}{Time}\\\)
    • \(CPU执行时间 = CPU时钟周期数/主频 = （指令条数×CPI）*CPU时钟周期\)
    • \(MIPS = 指令条数 ÷ (执行时间×10^6) = 主频÷(平均CPI×10^6)\) 指的是每秒执行的多少百万条指令数
    • FLOPS（Floating-point Operation Per Second）：每秒执行多少浮点计算。用于评估用于科学计算的计算机的系统性能

    其他¶

    机器字长：即64位，32位，描述计算机进行一次整数运算所能处理的二进制位数。

    • 通常和CPU的寄存器位数、ALU有关。
    • 字长通常等于通用寄存器的位数或ALU的宽度

    数据通路带宽（width）：数据总线一次能传输的数据的位数

    吞吐量：单位时间内，系统能够处理的请求的数量

    • 吞吐量，通常取决于主存的存取周期（主存也有频率）。

    响应时间：指从发送请求开始，到系统做出响应给出结果时结束，所需要花费的时间。
