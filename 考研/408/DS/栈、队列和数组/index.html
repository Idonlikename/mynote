    栈、队列和数组¶

    栈、队列和数组都是线性结构的具体形式。考研中不仅考查它们的定义和基本操作，还常把它们与表达式、递归、树的遍历和矩阵存储结合起来考查。

    栈¶

    栈（Stack）是一种只允许在一端进行插入和删除的线性表。允许插入和删除的一端称为栈顶，另一端称为栈底。

    栈的特点是后进先出（LIFO，Last In First Out）：最后入栈的元素最先出栈。

    基本操作¶

    • InitStack：初始化空栈。
    • Push：将元素压入栈顶。
    • Pop：删除并返回栈顶元素。
    • GetTop：读取栈顶元素但不删除。
    • StackEmpty：判断栈是否为空。

    对空栈执行 Pop 称为下溢；顺序栈已满仍执行 Push 称为上溢。上溢是存储空间不足，下溢是当前栈中没有可删除的元素。

    顺序栈¶

    顺序栈用数组保存元素，用 top 表示栈顶。具体定义有两种常见约定：

    • top 指向当前栈顶元素，空栈时设为 -1。
    • top 指向下一个可插入位置，空栈时设为 0。

    做题时必须先确认 top 的定义，否则入栈、出栈和判空条件会整体错位。

    链栈¶

    链栈用链表保存元素，通常把链表头作为栈顶。这样入栈和出栈都只需要修改头指针，不需要移动其他结点。

    栈的应用¶

    • 括号匹配：左括号入栈，遇到右括号时检查栈顶是否为对应的左括号。
    • 表达式求值：使用运算符栈和操作数栈处理优先级和结合性。
    • 递归模拟：递归调用过程可以用栈保存返回地址、参数和局部变量。
    • 深度优先搜索：DFS 可以用显式栈替代递归实现。
    • 进制转换和回文判断：利用栈的逆序特性处理数据。

    中缀表达式转后缀表达式时，数字直接输出，运算符入栈；遇到右括号就弹出到左括号为止，遇到普通运算符则先弹出栈顶所有优先级不低于当前运算符的运算符，再压入当前运算符；扫描结束后弹出剩余运算符。后缀表达式求值时，遇到操作数入栈，遇到运算符弹出右操作数和左操作数，计算后再入栈，注意减法和除法的顺序。

    栈的计数公式：卡特兰数¶

    若有 n 个不同元素按 1,2,...,n 的固定顺序入栈，允许随时入栈或出栈，合法的出栈序列数为： \(\(C_n=\frac{1}{n+1}\binom{2n}{n}\)\)

    这里的前提是入栈顺序固定。把一次入栈记为 (、一次出栈记为 )，合法序列必须满足：

    • 总共有 n 次入栈和 n 次出栈；
    • 扫描任意前缀时，出栈次数不能多于入栈次数；
    • 扫描结束时入栈次数和出栈次数相等。

    因此，合法的栈操作序列数、固定输入顺序下的合法出栈序列数，都等于卡特兰数。常用递推式为： \(\(C_0=1,\qquad C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}\)\)

    例：1,2,3 按顺序入栈时，合法出栈序列共有 \(\(C_3=\frac{1}{4}\binom{6}{3}=5\)\) 个，分别可以是 123、132、213、231、321；312 不可能，因为要先弹出 3，必须先弹出 2，而 2 会出现在 3 前面。

    不要把这个公式用于“输入顺序也可以任意排列”的题目；若只问任意排列数量，则是 \(n!\)，不是卡特兰数。

    队列¶

    队列（Queue）是一种只允许在一端插入、另一端删除的线性表。插入的一端称为队尾，删除的一端称为队头。

    队列的特点是先进先出（FIFO，First In First Out）：最先入队的元素最先出队。

    基本操作¶

    • InitQueue：初始化空队列。
    • EnQueue：从队尾插入元素。
    • DeQueue：从队头删除并返回元素。
    • GetHead：读取队头元素但不删除。
    • QueueEmpty：判断队列是否为空。

    循环队列¶

    顺序队列使用数组存储时，队头出队后前面的空间可能无法利用。把数组首尾相接，就得到循环队列。指针移动通常写成：

    Text Only
    next = (current + 1) % MaxSize

    循环队列有两种常见的判空、判满方法：

    1. 牺牲一个存储单元：队空时 front == rear，队满时 (rear + 1) % MaxSize == front，实际最多存储 MaxSize - 1 个元素。
    2. 增加 size 或标志位：用额外信息区分队空和队满，可以使用全部数组空间。

    采用“牺牲一个存储单元”、front 指向队头元素、rear 指向下一个入队位置的约定时：

    Text Only
    队空：front == rear
队满：(rear + 1) % MaxSize == front

EnQueue(x):
    if 队满: 失败
    data[rear] = x
    rear = (rear + 1) % MaxSize

DeQueue():
    if 队空: 失败
    x = data[front]
    front = (front + 1) % MaxSize
    return x

队列长度 = (rear - front + MaxSize) % MaxSize

    若题目规定 rear 指向当前队尾元素，以上条件和更新式要整体改写；不要只替换一个判空条件。循环队列容量为 MaxSize 时，牺牲一个单元后最多存 MaxSize-1 个元素。

    链队列¶

    链队列通常用带头结点的单链表实现，并设置 front 和 rear 指针。入队在队尾进行，出队在队头进行。空队列时，两个指针的关系必须在初始化和最后一个元素出队时保持一致。

    双端队列和优先队列¶

    • 双端队列：允许在队头和队尾进行插入或删除。
    • 优先队列：出队顺序由优先级决定，而不是简单遵守先进先出。堆是实现优先队列的常用结构。

    普通队列、双端队列和优先队列的操作规则不同，不能混用它们的判定条件。

    队列的应用¶

    • 层序遍历：二叉树的层序遍历使用队列。
    • 广度优先搜索：BFS 按距离由近到远访问顶点。
    • 操作系统和网络中的缓冲：生产者产生数据入队，消费者从队头取数据。
    • 模拟排队过程：按照到达顺序处理任务。

    数组¶

    数组（Array）是由相同类型的数据元素构成的有限序列，元素通常保存在连续存储单元中，并通过下标定位。

    • 一维数组可以看作线性表的顺序存储。
    • 二维及以上数组是多维数组，每个元素由多个下标共同确定。
    • 数组适合随机访问，但在中间位置插入或删除元素时通常需要移动大量元素。

    二维数组地址计算¶

    设二维数组 A 有 m 行 n 列，每个元素占 L 个存储单元，起始地址为 LOC(A[0][0])。

    按行优先存储时：

    \[ LOC(A[i][j])=LOC(A[0][0])+(i\times n+j)\times L \]

    按列优先存储时：

    \[ LOC(A[i][j])=LOC(A[0][0])+(j\times m+i)\times L \]

    三维和更高维数组的地址计算也是相同思想：先确定当前下标之前包含多少个完整的低维数组，再乘以元素大小。

    特殊矩阵¶

    • 对角矩阵：非零元素主要位于主对角线附近。
    • 三角矩阵：主对角线一侧的元素全部为零，包括上三角矩阵和下三角矩阵。
    • 对称矩阵：满足 A[i][j] = A[j][i]，只需保存主对角线及一侧元素。
    • 带状矩阵：非零元素集中在主对角线附近的若干条带上。

    压缩存储的关键是建立二维下标与一维存储位置之间的映射。考题通常要求先判断元素位于哪一部分，再计算它在压缩数组中的下标。

    稀疏矩阵¶

    稀疏矩阵是非零元素远少于零元素的矩阵。常用的表示方法有：

    • 三元组表：每个非零元素保存行号、列号和值。
    • 十字链表：同时沿行和列建立链表，适合非零元素动态变化的场景。

    考点提示

    栈关注“同一端进出”，队列关注“两端分工”；循环队列的关键是取模和队空/队满条件；数组地址题的关键是下标起点、存储顺序和元素大小。
