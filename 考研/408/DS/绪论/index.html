    绪论¶

    • 数据是信息的载体，在计算机中也就是1和0。具体来说，是所有被输入到计算机的 0 1的集合。
    • 数据对象是具备相同性质的数据元素的集合，是数据的一个子集。
    • 数据元素是数据的基本单位，通常作为一个整体去考虑。由多个数据项组成

    其之间的关系可以展示为：数据（万物）>数据对象（所有学生）>数据元素（一个学生）>数据项（学生的身高）

    数据类型：

    • 原子类型：值不可再分的数据类型
    • 结构类型：值可再分的数据类型
    • 抽线数据类型（ADT）：一个数学模型及定义在该数学模型上的一组操作。可以理解为结构体。ADT（数据对象，数据关系，基本操作集）

    数据结构¶

    数据结构是相互之间存在一种或多种特定关系的数据元素的集合，元素之间的关系称作结构。

    数据结构三要素包括：逻辑结构、存储结构和数据的运算。

    也就是说一个完整的数据结构，必须包括逻辑结构、存储结构和数据的运算

    逻辑结构¶

    逻辑结构描述的是数据元素之间的逻辑关系，其与数据的存储无关，独立于计算机。可分为线性结构和非线性结构。

    除按是否为线性结构进行区分，也可以按照元素之间的关系进行区分，以下介绍其中四类基本逻辑结构关系：

    1. 集合：结构中的数据元素仅同属于一个集合，无其他关系
    2. 线性结构：结构中的数据元素存在一对一的关系
    3. 树状结构：存在一对多的关系
    4. 网状结构：多对多的关系

    存储结构¶

    指的是数据结构在计算机中的实现（关注如何在计算机中实现），也可以成为映像或表示。存储结构也可以称作物理结构，它不仅仅包括数据元素的表示也包含关系的表示。

    可分为以下几种存储结构：

    1. 顺序存储。数据元素存储在相邻的存储单元中。
    2. 链式存储。数据元素借助元素存储地址指针实现线性结构。
    3. 索引存储。在存储信息的同时，还要建立索引表。索引方式为 key->location->value。
    4. 散列存储。为hash存储，可通过关键字key依靠散列函数直接计算出该元素value的存储地址，索引方式为key->value。
    存储结构 优点 缺点
    顺序存储 可以实现随机存取（直接存取） 只能使用相邻的一整块存储单元，可能产生较多的外部碎片
    链式存储 不会出现碎片现象，能够充分利用存储单元 依靠指针实现线性结构，占用额外空间，只能实现顺序存取
    索引存储 检索速度快 索引表占用额外空间。增删改查也要修改索引表，增加时间开销
    散列存储 检索，增删改查都很快 散列函数不好，出现元素存储单元冲突，解决冲突会增加空间和时间开销

    随机存取：指的是访问某个数据元素（信息）与其存储位置无关，可以依靠其下标直接访问。访问任何位置的数据元素花费均为\(O(1)\)

    顺序存取：也叫非随机存取，不能通过下标访问，在存取第\(N\)个数据时，必须先访问前\((N-1)\)个数据。

    数据的运算¶

    由逻辑结构和实际需求来定义，其定义针对逻辑结构，指出运算的功能。

    实现针对存储结构，指出运算的具体操作步骤。

    算法¶

    算法是对特定问题求解步骤的一种描述。

    算法的具有五种特性

    1. 有穷性：一个算法总在执行有穷步后结束，且每一步在有穷的时间内完成。（算法必须在有限步骤后结束）
    2. 确定性：算法的每条指令都是确定的，对于相同的输入只会得到相同的输出。（每一步都有清晰定义的操作）
    3. 可行性：算法的操作可以通过已经实现的基本运算执行有限次来实现。（每一步都可以实际执行）
    4. 输入：算法由1个或多个输入
    5. 输出：算法由1个或多个输出

    一个好算法所需要考虑达到的目标：

    1. 正确性：能够正确求解问题
    2. 可读性：具有良好的可读性
    3. 健壮性：对于非法数据也能够处理，而非产生奇怪的输出。
    4. 高效率和低存储量需求。时间复杂度和空间复杂度
