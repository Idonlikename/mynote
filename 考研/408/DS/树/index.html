    树¶

    树是一种非线性数据结构。除根结点外，每个结点有且只有一个直接前驱，所有结点可以沿着父子关系组织成层次结构。树中不存在回路。

    基本概念¶

    • 结点的度：结点拥有的孩子数。
    • 树的度：树中所有结点度的最大值。
    • 根结点：没有双亲的结点。一棵非空树只有一个根结点。
    • 双亲和孩子：直接相连且位于上一层的结点称为双亲，下一层的结点称为孩子。
    • 兄弟结点：具有同一个双亲的结点互为兄弟。
    • 叶结点：度为 0 的结点。
    • 分支结点：度大于 0 的结点，也称非终端结点。
    • 路径：从一个结点沿着边到达另一个结点所经过的结点序列；路径上的边数称为路径长度。
    • 层次：根结点通常记为第 1 层，结点层次等于其深度加 1。
    • 结点的深度：从根结点到该结点经过的边数。
    • 树的高度：树中结点的最大深度。
    • 子树：以树中某个结点为根，并包含该结点全部后代的树。
    • 森林：若干棵互不相交的树组成的集合。

    二叉树¶

    二叉树中的每个结点最多有两个孩子，分别称为左孩子和右孩子。左右次序不能互换，因此二叉树和普通的二叉树形树不同。二叉树可以为空；非空二叉树由一个根结点、左子树和右子树组成。

    常见类型¶

    • 满二叉树：每一层都达到最大结点数。
    • 完全二叉树：除最后一层外都满，最后一层结点从左到右连续排列。
    • 平衡二叉树：任意结点的左右子树高度差不超过 1，考研中通常特指 AVL 树。
    • 二叉搜索树：左子树所有关键字小于根，右子树所有关键字大于根。
    • 线索二叉树：利用空指针域保存结点在某种遍历次序下的前驱或后继信息。

    二叉树的链式结点定义如下：

    C++
    struct Node {
    int key;
    Node* left = nullptr;
    Node* right = nullptr;
};

    遍历¶

    前序、中序和后序遍历的区别在于根结点访问时机：

    遍历 顺序
    前序 根、左、右
    中序 左、根、右
    后序 左、右、根
    层序 从上到下、从左到右
    C++
    void inorder(Node* root) {
    if (root == nullptr) {
        return;
    }
    inorder(root->left);
    cout << root->key << ' ';
    inorder(root->right);
}

    二叉树的前、中、后序遍历都能在线性时间内完成；递归调用栈空间与树高有关。

    二叉树的结点数量与遍历构造¶

    以下公式中的“高度”统一按层数计算：只有根结点的树高度为 1；若题目把根的深度记为 0，则树高要减 1。

    结点数量公式¶

    • 第 \(i\) 层最多有 \(2^{i-1}\) 个结点。
    • 高度为 \(h\) 的二叉树最多有 \(2^h-1\) 个结点，至少有 \(h\) 个结点。
    • 二叉树的边数等于结点数减 1：\(E=n-1\)。
    • 设 \(n_0,n_1,n_2\) 分别表示度为 0、1、2 的结点数，则 \(\(n=n_0+n_1+n_2,\qquad n_0=n_2+1\)\) 因为二叉树的边数既等于 \(n-1\)，又等于 \(n_1+2n_2\)。
    • 若是非空满二叉树，高度为 \(h\) 时共有 \(2^h-1\) 个结点、\(2^{h-1}\) 个叶结点。
    • 含 \(n\) 个结点的完全二叉树按层编号时，最后一个非叶结点编号为 \(\lfloor n/2\rfloor\)；从 1 开始编号的结点 \(i\) 的孩子是 \(2i\) 和 \(2i+1\)。
    • 任意树有 \(n\) 个结点时边数一定为 \(n-1\)；若是满 \(m\) 叉树，度为 0 的结点数与度为 \(m\) 的结点数满足 \(n_0=(m-1)n_m+1\)。
    • 满 \(m\) 叉树第 \(i\) 层最多有 \(m^{i-1}\) 个结点，高度为 \(h\) 时最多有 \(\frac{m^h-1}{m-1}\) 个结点；\(m=2\) 时退化为二叉树公式。

    结点数计算例题¶

    • 若二叉树有 \(n_0=5\) 个叶结点，则 \(n_2=n_0-1=4\)。若另有 \(n_1=3\)，总结点数为 \(n=5+3+4=12\)。
    • 若是满二叉树且总结点数为 31，则高度为 \(h=\log_2(31+1)=5\)，叶结点数为 \(2^{h-1}=16\)，度为 2 的结点数为 15。
    • 若是完全二叉树且有 13 个结点，则高度为 \(\lfloor\log_2 13\rfloor+1=4\)，叶结点数为 \(\lceil 13/2\rceil=7\)，非叶结点数为 \(\lfloor 13/2\rfloor=6\)。

    做题时先判断题目说的是普通二叉树、满二叉树还是完全二叉树，再套公式；普通二叉树只知道总结点数和高度时，通常只能得到范围，不能直接套满二叉树公式。

    树形结构数量与结点数量的区别¶

    若题目问“有 \(n\) 个结点能构成多少种不同二叉树”，问的是结构数量而不是某棵树有多少结点，答案是卡特兰数： \(\(C_n=\frac{1}{n+1}\binom{2n}{n}\)\)

    它也满足递推式 \(C_0=1\)，\(C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}\)。例如 \(n=3\) 时有 \(C_3=5\) 种二叉树结构；含 \(n\) 个不同关键字的不同二叉搜索树数量也为 \(C_n\)。若题目问满二叉树且有 \(n\) 个内部结点，则结构数量为 \(C_n\)；若给的是总结点数 \(2n+1\)，再把内部结点数换算为 \(n\)。

    例：一棵二叉树有 10 个结点，其中 2 个结点只有左孩子，求叶结点数。由 \(\(n_0=n_2+1,\quad n_0+n_1+n_2=10\)\) 还需要知道 \(n_2\) 或 \(n_1\) 才能唯一确定答案；“只有左孩子”只是度为 1，不能直接当作叶结点。若题目另给出 \(n_1=3\)，则 \(n_0+n_2=7\) 且 \(n_0=n_2+1\)，得到 \(n_0=4,n_2=3\)。做计数题时先检查条件是否满足整数性。

    由遍历序列还原二叉树¶

    还原的核心是：前序的第一个元素或后序的最后一个元素确定根；中序序列确定左右子树的范围。

    1. 前序序列取第一个结点作为根，在中序序列中找到根的位置。
    2. 中序根左侧是左子树，右侧是右子树，按左子树结点数把前序剩余部分切开。
    3. 对左右区间递归执行上述过程，直到区间为空。

    例：前序为 A B D E C F，中序为 D B E A F C。

    Text Only
    根 A
中序分割：左 [D B E]，右 [F C]
左子树前序 [B D E]，右子树前序 [C F]
根 B：中序 [D] B [E]
根 C：中序 [F] C []

    因此树为 A(B(D,E), C(F,∅))，后序为 D E B F C A。中序与后序的还原过程相同，只是每次取后序区间的最后一个结点作为根。仅有前序和后序通常不能唯一还原二叉树；若再说明是满二叉树，才可能唯一确定。

    堆的建堆与调整¶

    以大根堆为例，按 1 开始编号：

    1. 叶结点天然满足堆序，从最后一个非叶结点 \(\lfloor n/2\rfloor\) 开始向前处理。
    2. 对结点 \(i\)，比较它与左右孩子，把最大者换到父结点位置。
    3. 若发生交换，继续让下移的元素与新位置的孩子比较，直到满足堆序或到达叶结点。
    4. 依次处理到根，得到大根堆。建堆是 \(O(n)\)，不是把 \(n\) 个元素逐个插入导致的 \(O(n\log n)\)。

    插入元素时先放在数组末尾，再不断与父结点比较并上浮；删除堆顶时用最后一个元素补到根，再向下调整。两种操作最坏都是 \(O(\log n)\)。

    树、森林与二叉树的转换¶

    树可以用“孩子兄弟表示法”转换为二叉树：结点的第一个孩子作为左孩子，结点的下一个兄弟作为右孩子。转换后，原树的同层兄弟会沿右指针连接。

    例如原树中 A 的孩子依次为 B、C、D，B 的孩子为 E、F，C 的孩子为 G，转换时逐结点执行：

    Text Only
    A.left = B          // 第一个孩子
B.right = C         // B 的下一个兄弟
C.right = D         // C 的下一个兄弟
B.left = E          // B 的第一个孩子
E.right = F         // E 的下一个兄弟
C.left = G          // C 的第一个孩子

    转换后二叉树中，左指针只表示第一个孩子，右指针只表示下一个兄弟；不能把原树的第二个孩子直接放成二叉树右孩子。

    森林中的每棵树先分别转换为二叉树，再把前一棵树的根结点作为后一棵树根结点的右孩子。反向转换时，左指针表示第一个孩子，沿右指针可以找到其他兄弟。

    树的先根遍历对应二叉树的前序遍历，树的后根遍历对应二叉树的中序遍历；森林的先序遍历对应转换后二叉树的前序遍历。

    线索二叉树¶

    含有 n 个结点的二叉树有 n+1 个空指针域。线索二叉树利用这些空指针保存遍历序列中的前驱或后继：

    • lchild 为空时，可以改为指向前驱；
    • rchild 为空时，可以改为指向后继；
    • 需要用标志位区分“孩子指针”和“线索指针”。

    线索化的目的，是在不使用递归或辅助栈的情况下快速找到遍历前驱和后继。

    哈夫曼树与并查集¶

    哈夫曼树¶

    带权路径长度（WPL）是所有叶结点的权值乘以其路径长度之和。哈夫曼树是给定带权叶结点集合后 WPL 最小的二叉树。

    构造方法是反复选取权值最小的两棵树合并为新树，并把新树的权值设为两者之和。哈夫曼编码规定左分支和右分支分别使用不同二进制位，因此得到的编码具有前缀无歧义性。

    手算时维护一个权值集合，每轮取最小的两个数合并，并把新数放回集合。若权值为 2, 3, 7, 9：

    Text Only
    2+3=5       集合变为 5,7,9
5+7=12      集合变为 9,12
9+12=21     根权值为 21

    WPL 可以直接把每轮产生的新结点权值相加：\(5+12+21=38\)；也可以在树画出后计算每个叶子的“权值 × 深度”。编码时从根到叶，左、右分支分别记为 0、1，左右取反不会改变 WPL。

    并查集¶

    并查集用于维护若干个互不相交的集合，基本操作为：

    • Find：确定元素所属集合的代表元。
    • Union：合并两个不同集合。

    常用优化包括按秩合并和路径压缩。二者结合后，单次操作的均摊复杂度接近常数，Kruskal 算法常用并查集判断两顶点是否已连通。

    Text Only
    Find(x):
    if parent[x] != x:
        parent[x] = Find(parent[x])   // 路径压缩
    return parent[x]

Union(x, y):
    rx = Find(x), ry = Find(y)
    if rx == ry: return false          // 会形成回路
    将秩小的根挂到秩大的根下
    return true

    判断两个顶点是否在同一集合只需比较 Find(x) 和 Find(y) 的结果；Kruskal 中只有 Find 不同才选边，选边后执行 Union。

    二叉搜索树¶

    在二叉搜索树中查找、插入和删除都沿着比较结果向左或向右移动。若树较平衡，平均复杂度为 \(O(\log n)\)；若每次都向同一侧增长，树会退化，复杂度变为 \(O(n)\)。

    删除结点时分三种情况：

    1. 叶结点，直接删除。
    2. 只有一个孩子，用孩子替代当前结点。
    3. 有两个孩子，用中序后继或中序前驱替换，再删除被替换的结点。

    堆¶

    堆是一种完全二叉树，常用数组保存。大根堆的每个父结点不小于孩子，小根堆的每个父结点不大于孩子。

    若数组下标从 0 开始，结点 i 的孩子下标为 2*i+1 和 2*i+2，父结点下标为 (i-1)/2。

    堆可以支持优先队列：插入和删除堆顶的复杂度为 \(O(\log n)\)，查看堆顶为 \(O(1)\)，建堆可以在线性时间内完成。

    考试判断

    二叉搜索树的中序遍历结果一定是递增序列；完全二叉树适合顺序存储；普通二叉树不能直接使用堆的下标关系。
