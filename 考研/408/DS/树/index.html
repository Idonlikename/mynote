    树¶

    树是一种非线性数据结构，用来表示一对多的层次关系。它的结构是递归的：一棵树由根结点和若干棵互不相交的子树组成，子树本身又是树。树中除根结点外，每个结点有且只有一个直接前驱（双亲）；沿着父子关系从根往下走，不会回到已走过的结点，所以树中不存在回路。

    抓住两点

    树的题目几乎都能靠两条性质做出来：一是递归（子树仍是树，可以套用同一套结论），二是边数恒为 \(n-1\)（\(n\) 个结点的树，边数一定比结点数少 1）。后面 \(n_0=n_2+1\) 之类的公式都是由第二条推出来的。

    基本概念¶

    • 结点的度：结点拥有的孩子个数。
    • 树的度：树中所有结点度的最大值。\(m\) 叉树即规定每个结点最多有 \(m\) 个孩子的树。
    • 根结点：没有双亲的结点。一棵非空树有且只有一个根结点。
    • 双亲和孩子：直接相连且位于上一层的结点称为双亲，下一层的结点称为孩子。
    • 兄弟结点：具有同一个双亲的结点互为兄弟。
    • 堂兄弟结点：双亲在同一层的结点互为堂兄弟。
    • 祖先和子孙：从某结点到根结点路径上的所有结点（不含该结点本身）都是它的祖先；以某结点为根的子树中的所有结点（不含该结点本身）都是它的子孙。
    • 叶结点：度为 0 的结点，也称终端结点。
    • 分支结点：度大于 0 的结点，也称非终端结点。
    • 路径：从一个结点沿着边到达另一个结点所经过的结点序列；路径上的边数称为路径长度。
    • 层次：根结点为第 1 层，其余结点的层次等于双亲层次加 1。
    • 结点的深度（层次）：408 真题里的“深度”按层数算，结点深度就是它所在的层数（根结点深度为 1），即“深度 = 层次”；只有部分算法教材按“从根出发的边数”定义深度（根为 0），那种口径比层数少 1，套公式前一律先换算成层数。
    • 结点的高度：从该结点向下到最远叶结点所经过的边数加 1，即该结点所在子树的层数；叶结点高度为 1。
    • 树的高度：树中结点的最大层次，只有根结点的树高度为 1，空树高度为 0；树的高度就是根结点的高度（同一道题里“深度”对结点和树要取同一口径）。
    • 子树：以树中某个结点为根，并包含该结点全部后代的树。子树之间互不相交。
    • 森林：\(m\)（\(m\ge 0\)）棵互不相交的树的集合。一棵树去掉根结点，剩下的子树集合就是森林；给森林中的每棵树加上同一个根结点，森林就变成一棵树。

    这些概念在选择题里怎么考

    • 边数：\(n\) 个结点的树有 \(n-1\) 条边，因此所有结点的度数之和 \(=n-1\)。
    • 度数分配：设度为 \(i\) 的结点有 \(n_i\) 个，则 \(\sum n_i=n\)，\(\sum i\cdot n_i=n-1\)，两式联立可反推各类结点的个数。
    • 度与孩子：度为 \(k\) 的结点恰有 \(k\) 个孩子，所以“某结点有 3 个孩子”和“该结点度为 3”是同一件事。
    • 高频陷阱：度为 2 的树不是二叉树。度为 2 的树指树中结点的最大度为 2，即至少有一个结点有 2 个孩子（所以这种树至少有 3 个结点），但它不要求每个结点都有 2 个孩子（叶结点度为 0），通常也不区分孩子的左右次序。二叉树则允许为空、允许只有根结点，而且结点只要有孩子就要区分左、右。至于“结点度为 1”，二叉树和度为 2 的树都允许，这一点不是两者的区别。

    二叉树¶

    二叉树是 \(n\)（\(n\ge 0\)）个结点的有限集合，它或为空，或由一个根结点和两棵互不相交的、分别称为左子树和右子树的二叉树组成。左、右子树是有次序的，即使某个结点只有一个孩子，也要说清它是左孩子还是右孩子——这是二叉树与度为 2 的树的本质区别。

    二叉树的 5 种基本形态：空树、只有根结点、只有左子树、只有右子树、左右子树都有。

    存储结构

    C++
    struct Node {
    int key;
    Node* left = nullptr;   // 左孩子
    Node* right = nullptr;  // 右孩子
};
    • 顺序存储：按完全二叉树的编号把结点放进数组。只有完全二叉树才不浪费空间；一般二叉树（尤其是单支树）会浪费大量单元，最坏情况是始终向右延伸的单支树（结点编号依次为 \(1,3,7,\dots,2^h-1\)），高度为 \(h\) 时要占用长度为 \(2^h-1\) 的数组；始终向左延伸时编号为 \(1,2,4,\dots,2^{h-1}\)，只需 \(2^{h-1}\) 个单元。顺序存储天然支持“\(i\) 的孩子是 \(2i\) 与 \(2i+1\)”的下标定位。
    • 链式存储（二叉链表）：每个结点有 2 个指针域，共 \(2n\) 个；除根结点外每个结点都被一条指针指向，即有 \(n-1\) 个指针域非空，所以空指针域有 \(2n-(n-1)=n+1\) 个。这个结论是线索二叉树的前提，也是常考的小结论。

    常见类型¶

    • 满二叉树：高度为 \(h\) 且含有 \(2^h-1\) 个结点，即每一层都达到最大结点数；叶结点全部集中在最后一层，不存在度为 1 的结点。
    • 完全二叉树：结点编号与同高度满二叉树的编号一一对应（中间不空号）。等价说法是：除最后一层外各层都满，且最后一层的结点从左到右连续排列。完全二叉树至多有一个度为 1 的结点，且该结点只有左孩子。
    • 二叉排序树（二叉搜索树）：左子树所有关键字 < 根 < 右子树所有关键字；中序遍历得到递增序列。
    • 平衡二叉树：任意结点的左右子树高度差（平衡因子 \(=\) 左子树高 \(-\) 右子树高）的绝对值不超过 1。考研中通常特指 AVL 树，其平衡因子只能取 \(1,0,-1\)。
    • 线索二叉树：利用空指针域保存结点在某种遍历次序下的前驱或后继信息。

    满二叉树与完全二叉树

    完全二叉树的编号性质是考试重点：从 1 开始编号时，结点 \(i\) 的左孩子为 \(2i\)、右孩子为 \(2i+1\)（不超过 \(n\) 才存在），双亲为 \(\lfloor i/2\rfloor\)。判断一棵树是否完全二叉树，就检查编号是否连续——若某结点有右孩子却没有左孩子，或出现了编号空洞，就不是完全二叉树。

    遍历¶

    前序、中序、后序遍历的区别只在于根结点在第几步访问，左右子树的相对顺序始终是“先左后右”：

    遍历 顺序 口诀
    前序（先序） 根、左、右 根在最前
    中序 左、根、右 根在中间
    后序 左、右、根 根在最后
    层序 从上到下、从左到右 逐层访问，借助队列
    C++
    void inorder(Node* root) {
    if (root == nullptr) {
        return;
    }
    inorder(root->left);            // 把下面三行换个位置，
    cout << root->key << ' ';       // 就能得到前序 / 中序 / 后序
    inorder(root->right);
}

    递归代码里“访问结点”那一步放在前面、中间、后面，分别对应前序、中序、后序，这是理解三种遍历最快的方式。

    性质与考点

    • 前序的第一个结点、后序的最后一个结点一定是根结点；中序序列中位于根结点左边的都是左子树的结点，右边都是右子树的结点。
    • 中序遍历二叉排序树得到递增有序序列，这是判定“是不是二叉排序树”最常用的方法。
    • 层序遍历用队列实现：出队一个结点就访问它，并把它的左右孩子依次入队。
    • 每个结点都恰好被访问一次，所以三种遍历的时间都是 \(O(n)\)；递归使用的调用栈深度与树高 \(h\) 有关，最坏（单支树）为 \(O(n)\)，最好（完全二叉树）为 \(O(\log n)\)。

    二叉树的结点数量与遍历构造¶

    以下公式中的“高度”统一按层数计算：只有根结点的树高度为 1。若题目改用“从根到结点的边数”定义深度，则给出的数字比层数少 1，要先换算成层数再套公式——先看题目口径，再套公式。

    结点数量公式¶

    • 第 \(i\) 层最多有 \(2^{i-1}\) 个结点。
    • 高度为 \(h\) 的二叉树最多有 \(2^h-1\) 个结点（满二叉树），至少有 \(h\) 个结点（每层只有一个结点的单支树）。
    • 二叉树的边数等于结点数减 1：\(E=n-1\)。
    • 设 \(n_0,n_1,n_2\) 分别表示度为 0、1、2 的结点数，则 \(\(n=n_0+n_1+n_2,\qquad n_0=n_2+1\)\) 推导：结点数 \(n\) 等于所有结点的度数之和加 1（每个结点被一条边连向双亲，只有根例外），而度数之和为 \(n_1+2n_2\)，所以 \(n=n_1+2n_2+1\)；与 \(n=n_0+n_1+n_2\) 联立得 \(n_0=n_2+1\)。这个结论与树的形状无关，对任何非空二叉树都成立。
    • 若是非空满二叉树，高度为 \(h\) 时共有 \(2^h-1\) 个结点、\(2^{h-1}\) 个叶结点，且不存在度为 1 的结点，于是 \(n_2=n_0-1=2^{h-1}-1\)。
    • 含 \(n\) 个结点的完全二叉树：高度为 \(\lfloor\log_2 n\rfloor+1\)；按层编号时最后一个非叶结点编号为 \(\lfloor n/2\rfloor\)，从 1 开始编号的结点 \(i\) 的孩子是 \(2i\) 和 \(2i+1\)。
    • 含 \(n\) 个结点的完全二叉树：叶结点数为 \(\lceil n/2\rceil\)，非叶结点数为 \(\lfloor n/2\rfloor\)。
    • 含 \(n\) 个结点的完全二叉树至多有 1 个度为 1 的结点，且该结点只有左孩子。由此可判奇偶：\(n\) 为奇数时每个非叶结点都有两个孩子，\(n_1=0\)；\(n\) 为偶数时有一个度为 1 的结点，\(n_1=1\)。
    • 任意树有 \(n\) 个结点时边数一定为 \(n-1\)；若是满 \(m\) 叉树，度为 0 的结点数与度为 \(m\) 的结点数满足 \(n_0=(m-1)n_m+1\)，这是 \(n_0=n_2+1\) 在 \(m\) 叉树上的推广。
    • 满 \(m\) 叉树第 \(i\) 层最多有 \(m^{i-1}\) 个结点，高度为 \(h\) 时最多有 \(\frac{m^h-1}{m-1}\) 个结点；\(m=2\) 时退化为二叉树公式。

    公式速查

    已知条件 结论
    任意非空二叉树 \(n_0=n_2+1\)，\(E=n-1\)
    高度 \(h\) 的二叉树 最少 \(h\) 个结点，最多 \(2^h-1\) 个结点
    第 \(i\) 层 最多 \(2^{i-1}\) 个结点
    非空满二叉树（高度 \(h\)） \(n=2^h-1\)，\(n_0=2^{h-1}\)
    完全二叉树（\(n\) 个结点） \(h=\lfloor\log_2 n\rfloor+1\)，\(n_0=\lceil n/2\rceil\)
    满 \(m\) 叉树 \(n_0=(m-1)n_m+1\)

    结点数计算例题¶

    • 若二叉树有 \(n_0=5\) 个叶结点，则 \(n_2=n_0-1=4\)。若另有 \(n_1=3\)，总结点数为 \(n=5+3+4=12\)。
    • 若是满二叉树且总结点数为 31，则高度为 \(h=\log_2(31+1)=5\)，叶结点数为 \(2^{h-1}=16\)，度为 2 的结点数为 15。
    • 若是完全二叉树且有 13 个结点，则高度为 \(\lfloor\log_2 13\rfloor+1=4\)，叶结点数为 \(\lceil 13/2\rceil=7\)，非叶结点数为 \(\lfloor 13/2\rfloor=6\)。
    • 100 个结点的完全二叉树：高度 \(\lfloor\log_2 100\rfloor+1=7\)；叶结点 \(\lceil 100/2\rceil=50\) 个，非叶结点 50 个；\(n\) 为偶数所以 \(n_1=1\)，再由 \(n_0=n_2+1\) 得 \(n_2=49\)。
    • 767 个结点的完全二叉树：叶结点 \(\lceil 767/2\rceil=384\) 个（编号 \(384\sim 767\)），最后一个非叶结点编号为 \(\lfloor 767/2\rfloor=383\)。

    做结点计数题时，先判断题目说的是普通二叉树、满二叉树还是完全二叉树，再套公式；只给总结点数和高度时，普通二叉树通常只能得到范围，不能直接套满二叉树公式。另外别忘了 \(n_1\) 的作用：\(n_0=n_2+1\) 只联系度为 0 和度为 2 的结点，\(n_1\) 必须由题目条件单独给出。

    树形结构数量与结点数量的区别¶

    若题目问“有 \(n\) 个结点能构成多少种不同二叉树”，问的是结构数量而不是某棵树有多少结点，答案是卡特兰数： \(\(C_n=\frac{1}{n+1}\binom{2n}{n}\)\)

    它也满足递推式 \(C_0=1\)，\(C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}\)：根占 1 个结点，左子树有 \(i\) 个结点、右子树有 \(n-1-i\) 个，两边结构数相乘再求和。

    • \(n=1,2,3,4\) 时分别有 \(1,2,5,14\) 种二叉树结构，例如 \(n=3\) 时有 \(C_3=5\) 种。
    • 含 \(n\) 个不同关键字的不同二叉搜索树数量也为 \(C_n\)（关键字给定，结构不同则 BST 不同）。
    • 若二叉树的每个分支结点都恰有 2 个孩子（即不存在度为 1 的结点，有的资料把这种树叫作“满二叉树”或“正规二叉树”），且这样的分支结点有 \(n\) 个，则结构数量为 \(C_n\)。注意这里的“满”是按“每个分支结点都有两个孩子”理解的；如果按前面“每层都满”的定义，满二叉树的形状由结点数唯一确定，根本不会有 \(C_n\) 种。若给的是总结点数 \(2n+1\)，先由 \(n_{\text{总}}=2n_{\text{分支}}+1\) 把分支结点数换算成 \(n\)。

    例：一棵二叉树有 10 个结点，还知道其中有 2 个结点只有右孩子，求叶结点数。由 \(\(n_0=n_2+1,\quad n_0+n_1+n_2=10\)\) 把两式联立消去 \(n_0,n_2\) 可得 \(2n_2+n_1=9\)，也就是说 \(n_1\) 必须是奇数。题目只说了“有 2 个结点只有右孩子”，并没有说度为 1 的结点一共有 2 个（这 2 个可能只是其中的一部分，也可能还有只有左孩子的结点），所以条件不足，答案不唯一：\(n_1\) 取 \(3,5,7,9\) 时叶结点数分别是 \(4,3,2,1\)。这里最容易错的两点，是把“有 2 个结点只有右孩子”直接当成 \(n_1=2\)，以及忽略 \(2n_2+n_1=9\) 的整数性（\(n_1=2\) 会算出 \(n_2=3.5\)，直接说明这组数据不可能）。若题目明确给出 \(n_1=3\)，则 \(n_0+n_2=7\) 且 \(n_0=n_2+1\)，得到 \(n_0=4,n_2=3\)，答案唯一。做计数题时先检查结果是否满足整数性（\(n_0,n_1,n_2\) 都必须是非负整数）。

    由遍历序列还原二叉树¶

    还原的核心是：前序的第一个元素或后序的最后一个元素确定根；中序序列确定左右子树的范围。

    1. 前序序列取第一个结点作为根，在中序序列中找到根的位置。
    2. 中序根左侧是左子树，右侧是右子树，按左子树结点数把前序剩余部分切开。
    3. 对左右区间递归执行上述过程，直到区间为空。

    例：前序为 A B D E C F，中序为 D B E A F C。

    Text Only
    根 A
中序分割：左 [D B E]，右 [F C]
左子树前序 [B D E]，右子树前序 [C F]
根 B：中序 [D] B [E]
根 C：中序 [F] C []

    因此树为 A(B(D,E), C(F,∅))，后序为 D E B F C A。中序与后序的还原过程相同，只是每次取后序区间的最后一个结点作为根。

    哪些组合能唯一确定一棵二叉树

    已知遍历序列 能否唯一确定 说明
    前序 + 中序 能 前序定根，中序分左右
    后序 + 中序 能 后序从末尾往前定根
    层序 + 中序 能 层序的第一个是根，中序分左右
    前序 + 后序 不能 只能确定各结点间的祖先关系，分不清只有一个孩子的结点是左还是右

    如果树中不存在度为 1 的结点（每个分支结点都恰有 2 个孩子），前序 + 后序就能唯一确定，满二叉树就属于这种情形。完全二叉树虽然可能有 1 个度为 1 的结点，但它的形状由结点数唯一决定（序列长度就是结点数），所以它的前序 + 后序同样能唯一还原。另外，只给一种遍历序列不一定能唯一确定：左单支链与右单支链的前序、层序都是 a b c d，单靠前序或层序无法区分两者；反过来，若题目已说明是完全二叉树，只给出层序序列就能还原整棵树（每个结点的位置由编号唯一决定）。

    树的应用¶

    堆的建堆与调整¶

    堆是一种完全二叉树，常用数组保存。大根堆的每个父结点不小于孩子，小根堆的每个父结点不大于孩子；堆只要求父子之间有大小关系，同一层的兄弟结点之间则没有要求。

    若数组下标从 0 开始，结点 i 的孩子下标为 2*i+1 和 2*i+2，父结点下标为 \(\lfloor (i-1)/2\rfloor\)（i = 0 是根，没有双亲，要单独判断，不能直接套这个式子）；若从 1 开始，孩子为 2i 和 2i+1，父结点为 \(\lfloor i/2\rfloor\)。从 1 开始编号时，编号大于 \(\lfloor n/2\rfloor\) 的结点都是叶结点，这正是建堆的起点依据。

    以大根堆为例，按 1 开始编号：

    1. 叶结点天然满足堆序，从最后一个非叶结点 \(\lfloor n/2\rfloor\) 开始向前处理（自底向上）。
    2. 对结点 \(i\)，比较它与左右孩子，把最大者换到父结点位置（这一步叫下沉）。
    3. 若发生交换，继续让下移的元素与新位置的孩子比较，直到满足堆序或到达叶结点。
    4. 依次处理到根，得到大根堆。

    建堆是 \(O(n)\)，而不是把 \(n\) 个元素逐个插入导致的 \(O(n\log n)\)。原因是“越靠下的结点越多、但能下沉的距离越短”：高度为 \(k\) 的结点最多有 \(\lceil n/2^{k+1}\rceil\) 个，每个最多下沉 \(k\) 次，总工作量约为 \(\sum_k k\cdot\dfrac{n}{2^{k+1}}=n\sum_k\dfrac{k}{2^{k+1}}\)，而 \(\sum_k k/2^{k+1}=1\)，所以总代价与 \(n\) 同阶。

    插入元素时先放在数组末尾，再不断与父结点比较并上浮；删除堆顶时用最后一个元素补到根，再向下调整。两种操作最坏都是 \(O(\log n)\)。

    堆可以支持优先队列：插入、删除堆顶 \(O(\log n)\)，查看堆顶 \(O(1)\)，建堆 \(O(n)\)。堆排序就是“建堆 \(O(n)\) + \(n\) 次删除堆顶 \(O(\log n)\)”，所以总复杂度为 \(O(n\log n)\)。

    考试判断

    二叉搜索树的中序遍历结果一定是递增序列；完全二叉树适合顺序存储；普通二叉树不能直接使用堆的下标关系。建堆 \(O(n)\)、插入/删除 \(O(\log n)\)、查看堆顶 \(O(1)\) 是选择题常考的复杂度结论。

    树、森林与二叉树的转换¶

    树可以用“孩子兄弟表示法”转换为二叉树：结点的第一个孩子作为左孩子，结点的下一个兄弟作为右孩子。转换后，原树中同一个双亲的兄弟会沿右指针串成一条链（不同双亲的堂兄弟不会被连起来）。

    例如原树中 A 的孩子依次为 B、C、D，B 的孩子为 E、F，C 的孩子为 G，转换时逐结点执行：

    Text Only
    A.left = B          // A 的第一个孩子
B.right = C         // B 的下一个兄弟
C.right = D         // C 的下一个兄弟
B.left = E          // B 的第一个孩子
E.right = F         // E 的下一个兄弟
C.left = G          // C 的第一个孩子

    转换后二叉树中，左指针只表示第一个孩子，右指针只表示下一个兄弟；不能把原树的第二个孩子直接放成二叉树右孩子。

    森林中的每棵树先分别转换为二叉树，再把前一棵树的根结点作为后一棵树根结点的右孩子（第一棵树的根就是转换后二叉树的根）。反向转换时，左指针表示第一个孩子，沿右指针可以找到其他兄弟；把右指针全部断开，得到的每一棵二叉树就对应原来的一棵树。

    遍历的对应关系是：

    • 树的先根遍历（先访问根，再依次先根遍历每棵子树）对应转换后二叉树的前序遍历。
    • 树的后根遍历（先依次后根遍历每棵子树，再访问根）对应转换后二叉树的中序遍历。
    • 森林的先序遍历（依次先序遍历每棵树）对应转换后二叉树的前序遍历。
    • 森林的中序遍历（依次对每棵树做后根遍历）对应转换后二叉树的中序遍历。
    • 反过来说：任意一棵二叉树都能唯一对应一棵树或一个森林，所以二叉树的遍历算法可以直接用来遍历树和森林。

    考试里常这样出：给出树或森林的遍历序列，要求写出对应二叉树的遍历序列；只要记住“先根 ↔ 前序、后根 ↔ 中序”，转换时不必真的画出二叉树。

    线索二叉树¶

    含有 \(n\) 个结点的二叉树有 \(n+1\) 个空指针域（推导见“存储结构”一节）。线索二叉树利用这些空指针保存遍历序列中的前驱或后继：

    • lchild 为空时，可以改为指向前驱；
    • rchild 为空时，可以改为指向后继；
    • 需要用标志位区分“孩子指针”和“线索指针”：左标志位 ltag = 0 表示 lchild 指向左孩子、ltag = 1 表示指向前驱；右标志位 rtag 同理。

    依据线索化的遍历次序不同，分为先序线索、中序线索和后序线索。中序线索最常考，找前驱、后继的规则是：

    • 结点有左线索（ltag = 1）时，左指针直接指向前驱；否则其前驱是左子树的“最右下结点”。
    • 结点有右线索（rtag = 1）时，右指针直接指向后继；否则其后继是右子树的“最左下结点”。

    线索化的目的，是在不使用递归或辅助栈的情况下快速找到遍历前驱和后继，从而在线性时间内完成遍历。线索化本身只需遍历一次，时间复杂度 \(O(n)\)：用迭代（只维护 pre 等几个工作指针）实现时额外空间为 \(O(1)\)，用递归实现时工作栈为 \(O(h)\)，无论哪种都比“递归/栈遍历 + 额外找前驱后继”的代价小。线索化之后就能看出价值：中序遍历可以在 \(O(1)\) 额外空间内完成——有右线索就沿线索直接走向后继，没有右线索（rtag = 0）就进入右子树，再一路向左找到最左下结点。

    哈夫曼树与并查集¶

    哈夫曼树¶

    带权路径长度（WPL）是所有叶结点的权值乘以其路径长度之和。哈夫曼树是给定带权叶结点集合后 WPL 最小的二叉树，所以也叫最优二叉树。

    构造方法是反复选取权值最小的两棵树合并为新树，并把新树的权值设为两者之和。

    • 每次合并都会产生一个新的分支结点，\(n\) 个叶结点恰好需要合并 \(n-1\) 次，因此哈夫曼树共有 \(2n-1\) 个结点，且不存在度为 1 的结点。
    • 手算时维护一个权值集合，每轮取最小的两个数合并，并把新数放回集合。若权值为 2, 3, 7, 9：
    Text Only
    2+3=5       集合变为 5,7,9
5+7=12      集合变为 9,12
9+12=21     根权值为 21

    WPL 可以直接把每轮产生的新结点权值相加：\(5+12+21=38\)；也可以在树画出后计算每个叶子的“权值 × 路径长度”（路径长度按到根的边数算）：\(2\times3+3\times3+7\times2+9\times1=38\)，两种算法结果一定相同。

    哈夫曼编码规定左分支和右分支分别使用不同二进制位（如左 0 右 1），根到叶的路径位串就是该字符的编码，任一编码都不是另一编码的前缀，因此具有前缀无歧义性，解码时不会产生歧义。左右分支的 0、1 取反对 WPL 没有影响。

    哈夫曼树的这些结论爱考

    • 权值相同的两个结点可以互换，左右孩子也可以交换，所以哈夫曼树的形状不唯一，但 WPL 唯一。
    • WPL 也等于所有非叶结点（合并出来的结点）权值之和。
    • 由 \(n_0=n_2+1\) 与“无度为 1 的结点”可得 \(n=2n_0-1\)：只要知道字符集大小就能算出总结点数。
    • 哈夫曼编码的加权平均码长就是 WPL，它保证了平均码长最短。

    并查集¶

    并查集用于维护若干个互不相交的集合，通常用双亲表示法的数组实现（根结点的双亲为自身）：同一棵子树中的结点属于同一个集合，树的根就是该集合的代表元。基本操作为：

    • Find：确定元素所属集合的代表元。
    • Union：合并两个不同集合。

    常用优化包括按秩合并（把结点少的树挂到结点多的树下，避免树变高）和路径压缩（查找时把路径上的结点直接挂到根下）。二者结合后，单次操作的均摊复杂度接近于常数（\(O(\alpha(n))\)，\(\alpha\) 是增长极慢的反阿克曼函数），因此 \(n\) 次操作总时间近似 \(O(n)\)；只做路径压缩、不做按秩合并也足够快。Kruskal 算法常用并查集判断两顶点是否已连通。

    Text Only
    Find(x):
    if parent[x] != x:
        parent[x] = Find(parent[x])   // 路径压缩
    return parent[x]

Union(x, y):
    rx = Find(x), ry = Find(y)
    if rx == ry: return false          // 会形成回路
    将秩小的根挂到秩大的根下
    return true

    判断两个顶点是否在同一集合只需比较 Find(x) 和 Find(y) 的结果；Kruskal 中只有 Find 不同才选边，选边后执行 Union。用并查集统计连通分量个数时，初始有 \(n\) 个分量，每成功合并一次就减 1。

    二叉搜索树¶

    在二叉搜索树中查找、插入和删除都沿着比较结果向左或向右移动。若树较平衡，平均复杂度为 \(O(\log n)\)；若每次都向同一侧增长，树会退化成单支树（按有序序列依次插入时最典型），复杂度变为 \(O(n)\)。

    删除结点时分三种情况：

    1. 叶结点，直接删除。
    2. 只有一个孩子，用孩子替代当前结点。
    3. 有两个孩子，用中序后继（右子树中最左下的结点）或中序前驱（左子树中最右下的结点）替换当前结点的值，再删除那个被拿去替换的结点。

    例：下面这棵树的关键字依次按中序递增取为 10, 20, 30, 40, 50：

    Text Only
            40
       /  \
     20    50
    /  \
  10    30

    中序序列为 10 20 30 40 50。删除根 40 属于第 3 种情况：中序后继是右子树中最左下的结点 50（这里右子树只有一个结点），用 50 覆盖 40 的值，再删掉原来的叶结点 50，得到根为 50、左子树为 20(10,30)、右子树为空的树，中序序列变为 10 20 30 50，仍然递增。若用中序前驱 30 替换也可以，得到的中序序列同样递增，所以删除结果可能不唯一，但都满足二叉搜索树的性质。注意第 3 种情况只是把问题转化成前两种情况（被拿去替换的结点一定没有左子树或没有右子树），替换后还要继续删到底。

    本章最容易混的几点

    • 层数与深度：公式里的树高一律按层数算（只有根时高度为 1）；题目若用“从根到结点的边数”定义深度，给出的值比层数少 1，套公式前要换算。
      • 结点数 vs 结构数：“有多少个结点”问的是规模，“能构成多少种”问的才是卡特兰数（且只对“每个分支结点恰有 2 个孩子”的二叉树成立）。
      • 满 / 完全 / 普通：只有完全二叉树能用 \(\lceil n/2\rceil\) 数叶子，只有满二叉树能直接用 \(2^h-1\)。
      • 遍历还原：只有前序 + 后序（没有中序）时通常不能唯一还原；当树中不存在度为 1 的结点（满二叉树就是这种情形）时，前序 + 后序一定能唯一还原（完全二叉树是靠“结点数定形状”做到唯一还原的，与这一条无关）；而前序 + 层序同样不能唯一还原（左单支链与右单支链的前序、层序都是 a b c d）。
      • 树与二叉树：孩子兄弟转换后，右指针表示“兄弟”而不是“右孩子”，遍历对应关系是“先根 ↔ 前序、后根 ↔ 中序”。
