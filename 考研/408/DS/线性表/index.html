    线性表¶

    定义¶

    指的是具有相同数据类型的 \(n\) 个数据元素的有限序列（有次序），\(n\) 为表长，\(n=0\)时称作空表。用 \(L\) 表示可有一般表示： $$ L=(a_1,a_2...a_n) $$ \(a_1\)与\(a_n\) 分别称为表头元素和表尾元素。将每一个元素的后一个元素称作直接后继，前一个称作直接前驱

    一个线性表具备以下特点：

    • 有穷性：表中的元素个数有限
    • 有序性：表中元素具有逻辑上的顺序性，即表是有序表
    • 同一性：数据元素的数据类型相同，意味着其占有相同大小的存储空间
    • 每个元素都是数据元素，即不可再分的单个元素 （考研内容）
    • 表中元素具有抽象性，仅讨论元素之间的逻辑关系而不关注元素的具体内容 （考研内容）

    tips: 线性表中的元素为序从1开始，而数组元素下标从0开始。逻辑上从1开始，物理位置从0开始。

    操作¶

    主要操作为：

    InitList(&L)：初始化表

    Length(L)：求表长

    LocateElem(L,e)：按值查找

    GetElem(L,i)：按位查找，查找第 \(i\) 个位置上的值

    ListInsert(&L,i,e)：插入操作，按下标插入值

    ListDelete(&L,i,e)：删除操作

    PrintList(L)：输出操作

    Empty(L)：判空操作

    DestroyList(&L)：销毁操作。释放对应的内存空间

    对表进行更改的内容，都用指针取表地址 &L 若仅获取表信息，则仅仅用L

    线性表顺序表示¶

    定义¶

    用一组地址连续的存储单元，依次存储线性表中的数据元素，从而使得逻辑上相邻的两个元素在物理位置上同样相邻。第 \(i\) 个元素在存储位置上紧接着就是第 \(i+1\) 个元素，称 \(i\) 为 \(a_i\) 的位序。

    要点：逻辑顺序与存储的物理顺序相同

    由上，求第 \(i\) 个元素的地址，则可由第一个元素位置 \(loc(a_1)\) 得如下式： $$ loc(a_i)=loc(a_1)+(i-1)*sizeof(ElemType) $$ sizeof(ElemType)为元素在存储空间中所占的空间大小

    插入¶

    在顺序表L的第 \(i\) 个位置插入一个新元素 \(e\) 。若 \(i\) 不合法则返回 \(false\) 代表插入失败，反之，则将第 \(i\) 个元素后所有元素依次向后移动一个位置。

    bool ListInsert(SeqList &L, int i, ElemType e){
    if(i<1||i>L.length+1) // i不合法
        return false;
    if(L.length>=MaxSize) // 表超出空间大小
        return false;
    for(int j=L.length;j>=i;j--) //后移操作 key
        L.data[j]=L.data[j-1]; 
    L.data[i-1]=e;
    L.length++;
    return true
}

    最好情况：在表尾插入，无需后移，时间复杂度为\(O(1)\)

    最坏情况：在表头插入（\(i=1\)），将后移n次（所有元素都要后移），时间复杂度为\(O(n)\)

    平均情况：假设在第 \(i\) 个位置，那每个位置的插入概率应为 \(\frac{1}{n+1}\) （n为L.length）。则有下述公式： $$ \sum_{i=1}^{n+1}\frac{1}{n+1}(n-i+1)=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{1}{n+1}\frac{n(n+1)}{2}=\frac{n}{2} $$ 则平均时间复杂度应为：\(O(n)\)

    bool ListInsert(SeqList &L, int i, ElemType e){
    if(i<1||i>L.length+1) // i不合法
        return false;
    e=L.data[i-1]
    for(int j=i.length;j<L.length;j++) //前移操作 key
        L.data[j-1]=L.data[j]; 
    L.length--;
    return true
}

    最好情况：在表尾删除，无需位移，则有时间复杂度\(O(1)\)

    最坏情况：表头删除，需要位移 \(n-1\) 次，时间复杂度为\(O(n)\)

    平均情况：删除位置概率为 \(\frac{1}{n}\) 建立插入同理的公式，可得平均时间复杂度为\(O(n)\)

    按值查找（顺序查找）¶

    int  LocateElem(SeqList L，ElemType e)
{   
    i=0;      
    while ((i<=L.last)&&(L.elem[i]!=e) )     
        i++;  // 要么超出L的表长，要么找到元素的下表
    if  (i <= L.last)
         return(i+1); // 返回的是序号，而不是下标  
    else    
         return(-1); //没找到返回-1  
}

    最好情况：查找元素在表头，则有时间复杂度\(O(1)\)

    最坏情况：查找元素在表尾，则需要遍历整个表，时间复杂度为\(O(n)\)

    平均情况：查找位置概率为 \(\frac{1}{n}\) 建立前叙同理的公式，可得平均时间复杂度为\(O(n)\)

    void merge(SeqList *LA,  SeqList *LB,  SeqList *LC)
{ 
  i=0;j=0;k=0;
  while(i<=LA->last && j<=LB->last){
      if(LA->elem[i]<=LB->elem[j]){ 
          LC->elem[k]= LA->elem[i];  
          i++;  
          k++;    
      }else{    
          LC->elem[k]=LB->elem[j];   
          j++; 
          k++;     
      }
     while(i<=LA->last){    /*当表LA长则将表LA余下的元素赋给表LC*/
         LC->elem[k]= LA->elem[i];   
         i++;  
         k++;    
     }
     while(j<=LB->last){  /*当表LB长则将表LB余下的元素赋给表LC*/
         LC->elem[k]= LB->elem[j];   
         j++;  
         k++;    
     }
        LC->last=LA->last+LB->last+1;
  }

    总结¶

    优点：

    1.无需为表示结点间的逻辑关系而增加额外的存储空间；

    2.可方便地随机存取表中的任一元素。（随机存取）

    缺点：

    1.删插运算不方便，除表尾的位置外，在表的其它位置上进行插入或删除操作都必须移动大量的结点，其效率较低；

    2.由于顺序表要求占用连续的存储空间，存储分配只能预先进行静态分配。因此当表长变化较大时，难以确定合适的存储规模。

    线性表链式表示¶

    也就是不使用连续地址存储顺序表，采用指针来建立元素之间的逻辑关系。（非随机存取）

    单链表¶

    单链表，指的是单个指针域。即单个方向，指向后继。查找到第 \(i\) 个位置的元素，就难以回头查找 \(i-1\) 个位置的元素（可以依靠环实现，即表尾指针指向头指针）。

    定义¶

    指的是通过任意一组存储单元来存储线性表中的数据元素，对于单个链表结点，不仅要存储元素自身的信息，还要存储一个指向后继的指针。

    其中data为数据域，用来存储自身的信息；next为指针域，存储其后继结点的地址。

    两个域组成的存储映像（实现）称作Node-结点

    头指针（通常用L或者head指代）就是指向表头结点（可能是头结点（无信息），可能是第一个元素（带信息））的指针。

    头结点只是单个指针，是带头结点单链表的第一个结点，不存储信息。

    单链表分为带表头结点单链表，和不带表头结点单链表

    引入头结点的作用：

    • 省代码，可以保证第一个位置的操作和其他位置操作一致。无需特殊处理。
    • 给空表和非空表同样统一了操作。头指针均指向头结点。
